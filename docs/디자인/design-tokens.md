# Perky 디자인 토큰

색은 `app/globals.css`의 `@theme` 블록 **한 곳**에만 정의한다.
화면 파일에 `#2F4156` 같은 색값을 직접 쓰지 않는다. 토큰 이름으로만 쓴다.

**출처:** `docs/디자인/reference/color-reference.jpg`

## 지켜야 할 규칙

1. **`ink-200`, `ink-100`, `brand-200`, `sand-*` 위에 글씨를 올리지 않는다.**
   면과 보더 전용이다. 대비가 안 나온다.

2. **본문 텍스트는 `ink-600` 이상만 쓴다.**
   `ink-500`이 가장 옅게 허용되는 텍스트 색이고, 그보다 옅은 토큰은 없다.

3. **`brand-600`은 배경이나 큰 글씨로만 쓴다.**
   흰 배경 위 대비가 4.50:1로 본문 기준을 겨우 통과한다. 작은 보조 텍스트로 쓰면 안 된다.
   버튼 배경으로 쓸 때 그 위 글자는 흰색 (4.50:1).

4. **색을 새로 추가하려면 대비부터 확인한다.**
   기준: 본문 4.5:1, 18px 이상 굵은 글씨 3:1 (WCAG AA).
   확인 도구: https://webaim.org/resources/contrastchecker/

## 검증 기록

2026-08-18, 실제 사용 조합 18개를 전수 계산해 **전부 AA 통과**를 확인했다.

| 용도 | 조합 | 대비 |
|---|---|---|
| 제목 (지면 위) | `ink-900` / `sand-100` | 9.16 |
| 본문 (지면 위) | `ink-600` / `sand-100` | 4.92 |
| 보조·메타 (지면 위) | `ink-500` / `sand-100` | 4.54 |
| CTA 흰 글씨 | `white` / `brand-600` | 4.50 |
| 링크 버튼 흰 글씨 | `white` / `ink-900` | 10.44 |
| 태그 가능성 있음 | `ok-700` / `ok-50` | 5.44 |
| 태그 확인 필요 | `warn-800` / `warn-50` | 5.85 |
| 태그 해당 없음 | `ink-700` / `ink-100` | 5.75 |

> 계획서 초안이 쓰던 `text-slate-400`(날짜·확인일)은 흰 배경 대비가 2.77:1로
> 기준 미달이었다. `ink-500`(5.17:1)로 올렸다.

## 아직 안 정한 것

**금액 강조용 액센트 색이 없다.** 팔레트 5색이 전부 저채도라,
2층 결과 화면의 "최대 지원 가능액"을 크게 띄울 색이 부족하다.
1층은 금액을 계산하지 않으므로(PRD F0-9) 당장은 문제가 없지만,
2층 작업 전에 액센트 1색을 정해야 한다.

후보 방향: 베이지와 붙는 테라코타 계열, 또는 채도를 올린 틸.
