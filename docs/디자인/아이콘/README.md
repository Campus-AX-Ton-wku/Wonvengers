# 앱 아이콘

`perky-icon-2048.png` 이 **마스터**다. 모든 크기는 여기서 파생한다. 손으로 다시 그리지 않는다.

| | |
|---|---|
| 크기 | 2048 × 2048 |
| 배경 | `#2f6bff` (블루) |
| 마크 | `#ffffff` 흰색 소문자 `p` + 새싹 잎 두 장, 카운터(구멍)는 배경색이 비침 |
| 만든 방법 | Figma `Perky-Design` 의 `App Icon / Blue` (node `12:7`) 를 2× PNG 로 내보낸 뒤, 아트보드 회색(`#f5f5f5`) 모서리를 배경색으로 채워 풀블리드로 만듦 |
| 확정일 | 2026-09-03 |

**Figma 에서 다시 받을 때 주의**: 내보낸 PNG 는 둥근 모서리가 그려져 있고 그 바깥이
아트보드 회색이다. 그대로 구우면 iOS 홈 화면에 회색 모서리가 뜬다. 행마다 좌우
바깥쪽을 배경색으로 채워 가장자리까지 꽉 채운 뒤 마스터로 삼는다 — 라운딩은 OS 가 먹인다.

마스터를 실제로 재본 값이다. 파생 에셋을 만들거나 아이콘을 교체할 때 이 수치를 유지한다.

| 모서리 라운딩 | 없음 (OS가 먹임) | ✅ |
| 투명 픽셀 | 없음 (알파 제거) | ✅ |

| 안드로이드 안전원(지름 61.1%) | 마크 최대 반경 **90.5%** — 크게 초과 | ⚠️ 아래 참고 |
| 고유 색 수 | **35개** | ✅ 사실상 평면 |

## 남은 두 가지

### 1. 안드로이드 adaptive icon 안전영역을 크게 넘는다

마크 최대 반경이 90.5% 다. 마크가 캔버스를 거의 가득 채우는 디자인이라
옛 마스터(72.0%)보다 훨씬 크다.

- 권장 안전원 61.1% (지름 66/108dp)
- 실제 원형 마스크가 보여주는 66.7% (지름 72/108dp)

- **파비콘·iOS** — 영향 없다. 마크의 최대 반경 방향은 위아래이고, iOS 스퀘어클은
  세로 중심선에서 가장자리까지 닿는다.
- **안드로이드 adaptive / `purpose: "maskable"`** — 원형 마스크에서 실제로 깎인다.

대응은 마스커블용 파생을 만들 때 **마크를 67%로 축소**해서 굽는 것이다
(90.5% × 0.67 ≈ 60.6%, 안전원 안). 마스터는 그대로 두고 파생 단계에서 처리한다.
**옛 축소율 85% 를 그대로 쓰면 안 된다** — 마크가 커져서 안전원을 넘는다.

### 2. 브랜드 토큰과 배경색이 살짝 다르다

아이콘 배경은 `#2f6bff`, 매니페스트 `theme_color` 와 `brand-600` 은 `#1a6bef` 다.
스플래시·브라우저 UI 와 아이콘이 미세하게 다른 파랑이 된다. 나란히 놓고 보지 않으면
눈에 띄지 않아 그대로 뒀다. 맞추려면 Figma 심볼 쪽 색을 `brand-600` 으로 옮기는 게
맞다 — `brand-600` 은 흰 글씨 대비 4.78:1 이 걸려 있어 코드 쪽을 아이콘에 맞출 수 없다.

## 파생 에셋

전부 `perky-icon-2048.png` 에서 굽는다. 손으로 만들지 않는다.

| 파일 | 크기 | 용도 | 용량 |
|---|---|---|---|
| `apps/web/app/favicon.ico` | 16 · 32 · 48 | 브라우저 탭 | 2.9 KB |
| `apps/web/app/icon.png` | 512 | Next 기본 아이콘 + PWA 512 | 16.8 KB |
| `apps/web/app/apple-icon.png` | 180 | iOS 홈 화면 | 5.3 KB |
| `apps/web/public/icon-192.png` | 192 | PWA 런처 | 5.7 KB |
| `apps/web/public/icon-maskable-512.png` | 512 | 안드로이드 — 마크 67% 축소본 | 11.9 KB |

`favicon.ico` · `icon.png` · `apple-icon.png` 는 **Next 가 파일명만 보고 자동으로
`<link>` 태그를 넣는다.** `layout.tsx` 에 아이콘 메타데이터를 손으로 적지 않는다.

`public/icon-512.png` 는 두지 않는다 — `app/icon.png` 가 `/icon.png` 로 나가므로
매니페스트가 그걸 가리키면 된다. 따로 두면 같은 파일 151KB 가 두 벌 배포된다.

### 검증한 것 (2026-09-03 교체 시 재측정)

- `<link rel="icon">` · `apple-touch-icon` · `rel="manifest"` 가 HTML 에 주입됨
- **파생 4종 전부 테두리 이탈 0** — 가장자리까지 배경이 꽉 참
- **16px 파비콘에서 `p` 의 카운터(구멍)가 메워지지 않는다** — 마크 박스 안 배경색 픽셀 30개
- **마스커블 마크 최대 반경 60.5%** (안전원 61.1%) — 안드로이드 원형 마스크 안

### 다시 구울 때

```bash
# 마스터를 바꿨다면 파생을 전부 다시 굽는다.
# 일반: 마스터를 그대로 축소
# 마스커블: 마스터를 67% 로 줄여 배경색 캔버스 중앙에 붙인 뒤 축소
```

축소는 Lanczos 를 쓴다. **마크 크기가 달라졌으면 축소율부터 다시 구한다** —
`안전원 61.1 / 마스터의 마크 최대 반경(%)`. 구운 뒤 마스커블의 마크 최대 반경을
다시 재서 61.1% 안에 들어오는지 확인한다.

### 용량

Figma 벡터에서 나온 평면 PNG 라 파생이 전부 가볍다 (합계 42.6KB → 옛 아이콘 311KB).
옛 마스터의 모델 출력 노이즈(고유 색 2,456개) 문제가 교체와 함께 사라졌다.
