# 앱 아이콘

`perky-icon-1024.png` 이 **마스터**다. 모든 크기는 여기서 파생한다. 손으로 다시 그리지 않는다.

| | |
|---|---|
| 크기 | 1024 × 1024 |
| 배경 | `#527787` (슬레이트 블루) |
| 마크 | `#f9f5f2` (오프화이트) 소문자 `p`, 카운터(구멍)는 배경색이 비침 |
| 만든 방법 | 나노바나나(Gemini 이미지 모델) 생성 → JPEG 출력 → PNG 무손실 변환 |
| 확정일 | 2026-08-26 |

## 측정값

마스터를 실제로 재본 값이다. 파생 에셋을 만들거나 아이콘을 교체할 때 이 수치를 유지한다.

| 항목 | 값 | 판정 |
|---|---|---|
| 배경이 가장자리까지 꽉 찼나 | 테두리 588 표본 중 이탈 0 | ✅ |
| 모서리 라운딩 | 없음 (OS가 먹임) | ✅ |
| 마크 위치 | 중심 x 50.0% · y 50.0% | ✅ 정중앙 |
| 마크 크기 | 폭 39.9% · 높이 53.4% | ✅ |
| 여백 | 좌 30.0% 우 30.1% 상 23.2% 하 23.3% | ✅ 좌우 대칭 |
| 안드로이드 안전원(지름 61.1%) | 마크 최대 반경 **65.7%** — 픽셀 0.73% 초과 | ⚠️ 아래 참고 |
| 고유 색 수 | **3,446개** (평면 벡터라면 2~3개) | ⚠️ 아래 참고 |

## 남은 두 가지

### 1. 안드로이드 adaptive icon 안전영역을 살짝 넘는다

`p` 의 볼 위쪽 끝과 기둥 아래쪽 끝이 권장 안전원(지름 61.1%) 밖으로 4.6%p 나간다.
넘어가는 건 전체 마크 픽셀의 0.73%, 즉 **끝부분 살짝**이다.

- **파비콘·iOS·PWA 일반 아이콘** — 영향 없다. 마스크를 씌우지 않는다.
- **안드로이드 adaptive / `purpose: "maskable"`** — 원형 마스크에서 끝이 미세하게 깎일 수 있다.

대응은 마스커블용 파생을 만들 때 **마크를 92%로 축소**해서 굽는 것이다.
마스터는 그대로 두고 파생 단계에서 처리한다.

### 2. JPEG 링잉

생성 결과가 JPEG 이라 가장자리에 압축 잡티가 남았다. 평면 도형인데 고유 색이 3,446개다.
PNG 로 바꿔도 **이미 손실된 건 돌아오지 않는다** — 변환은 더 나빠지는 걸 막을 뿐이다.

1024px 와 큰 파생에서는 거의 안 보이고, 작은 파생은 축소하면서 묻힌다. 실무상 쓸 수 있다.
더 깨끗하게 가려면 둘 중 하나다.

- 나노바나나에서 **PNG 로 다시 출력**받는다 (같은 프롬프트·시드)
- 마스터를 **2색으로 정리**한다 — 밝기 임계로 나눠 배경 `#567c8d` · 마크 `#faf7f5` 로 다시 굽기.
  브랜드 토큰과 정확히 맞는다는 이점이 덤으로 붙는다 (지금은 `#527787` 로 살짝 어긋나 있다).

## 파생 에셋

아직 만들지 않았다. **앱에는 현재 아이콘이 하나도 없다** — 파비콘도, `apple-touch-icon` 도,
`manifest` 도 없어서 탭에 기본 아이콘이 뜨고 홈화면에 추가하면 스크린샷이 아이콘이 된다.

붙일 때 만들 것:

| 파일 | 크기 | 용도 |
|---|---|---|
| `apps/web/app/favicon.ico` | 32, 16 | 브라우저 탭 |
| `apps/web/app/icon.png` | 512 | Next.js 기본 아이콘 |
| `apps/web/app/apple-icon.png` | 180 | iOS 홈화면 |
| `apps/web/public/icon-192.png` | 192 | PWA manifest |
| `apps/web/public/icon-512.png` | 512 | PWA manifest |
| `apps/web/public/icon-maskable-512.png` | 512 | 안드로이드 — 마크 92% 축소본 |

`apps/web/app/manifest.json` 과 `layout.tsx` 메타데이터 연결도 함께 필요하다.
