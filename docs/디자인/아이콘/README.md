## 남은 두 가지

### 1. 안드로이드 adaptive icon 안전영역을 살짝 넘는다

마크 최대 반경이 72.0% 다. 기준 두 개 모두 넘는다.

- 권장 안전원 61.1% (지름 66/108dp)
- 실제 원형 마스크가 보여주는 66.7% (지름 72/108dp)

넘어가는 건 마크 픽셀의 4.71% — `p` 의 볼 위쪽 끝과 기둥 아래쪽 끝이다.

- **파비콘·iOS** — 영향 없다. iOS 스퀘어클 마스크는 이 각도에서 훨씬 넉넉하다.
- **안드로이드 adaptive / `purpose: "maskable"`** — 원형 마스크에서 실제로 깎인다.

대응은 마스커블용 파생을 만들 때 **마크를 85%로 축소**해서 굽는 것이다
(72.0% × 0.85 ≈ 61.2%, 안전원 안). 마스터는 그대로 두고 파생 단계에서 처리한다.

### 2. 색이 완전히 평면은 아니다

PNG 로 받았으니 압축 손실은 없다. 다만 모델 출력 자체에 미세한 노이즈가 있어
고유 색이 2,456개다 (평면 도형이면 2~3개). 눈에는 보이지 않고 축소하면 묻힌다.
실무상 쓸 수 있다.

완전히 평면으로 가려면 마스터를 **2색으로 정리**한다 — 밝기 임계로 나눠
배경 `#567c8d` · 마크 `#faf7f5` 로 다시 굽기. 브랜드 토큰(`brand-600`·`sand-50`)과
정확히 맞는다는 이점이 덤으로 붙는다. 지금은 `#527386` / `#f7f3f0` 으로 살짝 어긋나 있다.

## 파생 에셋

아직 만들지 않았다. **앱에는 현재 아이콘이 하나도 없다** — 파비콘도, `apple-touch-icon` 도,
`manifest` 도 없어서 탭에 기본 아이콘이 뜨고 홈화면에 추가하면 스크린샷이 아이콘이 된다.

붙일 때 만들 것:

| 파일 | 크기 | 용도 |
|---|---|---|
| `apps/web/app/favicon.ico` | 32, 16 | 브라우저 탭 |
| `apps/web/app/icon.png` | 512 | Next.js 기본 아이콘 |
| `apps/web/app/apple-icon.png` | 180 | iOS 홈화면 |
| `apps/web/public/icon-192.png` | 192 | PWA manifest |
| `apps/web/public/icon-512.png` | 512 | PWA manifest |
| `apps/web/public/icon-maskable-512.png` | 512 | 안드로이드 — 마크 85% 축소본 |

`apps/web/app/manifest.json` 과 `layout.tsx` 메타데이터 연결도 함께 필요하다.
