**F1-4 ✅ (2026-09-03 조건부로 고침)** — 전에는 모든 지역에 항상 물었다. 그런데 이 칸은
`lumpSumBasis: "oneTimeMoveCost"` 정책(익산 이사비·중개보수, 상한 50만원) 하나만 먹는 값이라,
지원 정책이 있는 줄 모르는 사람이 기본값 0 을 그대로 두면 "실제 지출 0원과 상한 50만원 중
작은 값 = 0원" 이 되어 지원이 통째로 사라졌다. 이제 그 정책이 있는 지역에서만 묻고,
묻기 전에 "익산시가 이 비용을 최대 50만원까지 지원해요" 를 먼저 말한다. 지원 정책이 없는
지역으로 바꾸면 남아 있던 값도 0 으로 지운다 (`findMoveCostPolicy`).

**F1-9 ❌ 철회 (2026-09-03)** — 고른 출처(`sourceType`)를 읽는 곳이 한 군데도 없었다. 결과에도
안 뜨고 계산에도 안 쓰여 스텝 2를 한 칸 늘리기만 했다. `"예시 데이터"` 선택지는 예시 채우기
버튼이 스텝 개편 때 사라지면서 도달 불가능해진 지 오래였고, 예시로 계산했다는 사실은
`exampleId` 가 따로 들고 있어 결과 배지(F1-11)에 그대로 뜬다. 필드를 지웠다.

**F1-8 ✅** — 금액 칸은 입력하는 즉시 만·억 단위로 읽어주고(`lib/money.ts`), 음수는 입력 자체가
0으로 막힌다. 다만 **필수값 누락**(지역·계약 시작일)은 `다음`을 누를 때 검증한다.

**F1-11 ⚠️ (기능 완료 · 데이터 미확인)** — `data/example-listings.json` + `lib/examples.ts` +
`/calculate` 첫 스텝의 "예시로 채워보기" 로 구현했다.

- 출처 배지를 화면에 그대로 띄운다: `가상 예시 · 실제 매물이 아닙니다` / `실제 매물 · YYYY-MM-DD 확인`
- `verifiedAt` 이 `null` 이면 `sourceKind` 에 뭐가 적혀 있어도 실제 매물로 표시하지 않는다
  (`isVerifiedExample`). 테스트로 고정했다.
- 예시를 불러와도 **F1-10 확인 체크박스는 켜지 않는다.** 사용자 본인의 진술을 앱이 대신
  켜면 위조다. 미확인 예시일 때는 체크박스 문구가 "실제 계약이 아닌 예시임을 알고 확인합니다"로 바뀐다.
- 결과 화면에도 "예시 매물 조건으로 계산한 결과" 배지를 띄운다. 이 화면은 캡처해서 공유되므로
  가상 조건으로 나온 금액이 실제 사례로 오해되면 안 된다.
- 계약 시작일은 예시에 넣지 않는다. 고정 날짜를 박아두면 시간이 지나 과거 날짜가 된다.

> [!IMPORTANT]
> **남은 일: 데이터 교체.** 두 예시는 시연용 가상 조건이다. 팀이 확인한 매물 조건으로 바꾸고
> `sourceKind` 를 `실제 매물`/`실거래 사례` 로, `verifiedAt` 에 확인 날짜를 넣어야 F1-11 이 완료된다.

**F4-2 ⚠️** — 충족·미충족·확인 필요를 `표` 대신 제목 + 불릿 목록으로 보여준다
(`app/result/page.tsx` 의 `RequirementList`). 모바일 폭에서 3열 표는 읽기 어려워 목록으로 뒀다.

**F4-3 ✅** — 감사에서 빠진 것을 확인해 구현했다. 정책 카드에 `지원 형태 · 지급 시점`을 적고,
금액 아래에 적용 산식을 문장으로 보여준다(`lib/benefit.ts` 의 `benefitFormula`·`payoutTiming`).
예: "월 환산 월세 400,000원과 월 상한 200,000원 중 작은 값 × 24개월 = 4,800,000원"

**F4-5 ✅** — 감사에서 빠진 것을 확인해 구현했다. 결과 상단에 최대 지원 가능액을 구성한
정책과 금액을 나열하고, 중복 수급 제한으로 빠진 정책은 충돌 상대와 함께 따로 보여준다
(`lib/combinations.ts` 의 `excludedByOverlap`).

**F4-11 ❌ 철회 (2026-08-24)** — `/result/summary` 전용 화면을 만들었다가 지웠다. 결과 화면
하나로 충분하다는 판단이고, 같은 숫자를 두 화면이 각자 보여주면 어긋날 여지만 남는다.
`lib/summary.ts` 의 `summaryHighlights` 는 `/result` 상단(F4-4)이 계속 쓴다.
