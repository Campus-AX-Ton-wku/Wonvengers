# 기능 요구사항 체크리스트 — 청년 주거지원 실부담 계산기

> 근거 문서: [`PRD.md`](./PRD.md) (2026-08-13, 6차 개정 — 설계 확정안)
> 이 문서는 PRD의 **2층(정밀 계산)** 요구사항을 F1~F4로 풀어 쓴 것이다.
> 1층(발견) 요구사항은 PRD의 F0-* 를 본다.
> 흐름: 주거비 입력 → 조건부 질문 → 규칙 기반 판정 → 최대 지원 가능액·최종 예상 주거비 → 신청 연결

---

## F1. 주거비·계약 조건 입력

| ID | 요구사항 | 우선순위 | 완료 |
|---|---|---|---|
| F1-1 | 거주 예정 지역을 시·군·구 단위로 입력받는다 | 필수 | ☐ |
| F1-2 | 계약형태를 월세·연세 중 선택하게 한다 | 필수 | ☐ |
| F1-3 | 보증금, 월세 또는 연세 선납액, 월 관리비를 입력받는다 | 필수 | ☐ |
| F1-4 | 선정 정책이 이사비·중개보수 등을 지원하면 해당 일시 지출을 추가로 입력받는다 | 필수 | ☐ |
| F1-5 | 계약 시작 예정일과 거주 예정 개월 수를 입력받는다 | 필수 | ☐ |
| F1-6 | 연세는 월 환산액(연세액 ÷ 계약 개월 수)을 함께 표시한다 | 필수 | ☐ |
| F1-7 | 관리비는 월세지원 대상 금액에 자동 포함하지 않는다 | 필수 | ☐ |
| F1-8 | 금액 단위와 입력 오류를 즉시 검증한다 | 필수 | ☐ |
| F1-9 | 입력값의 출처를 부동산 광고·중개사 안내·계약서 중 선택하게 한다 | 필수 | ☐ |
| F1-10 | 사용자가 "해당 매물의 실제 계약 조건과 일치함"을 확인한 뒤 계산을 시작한다 | 필수 | ☐ |
| F1-11 | 발표용 예시 매물은 팀이 직접 확인한 고정 데이터이며 실제 매물·실거래 사례 여부를 표시한다 | 필수 | ☐ |

## F2. 정책 판정용 조건부 질문

### 공통 입력 항목
본인(생년월일·현재상태) · 거주(지역·부모별도거주·전입신고) · 주택(무주택·계약자명의) · 가구(가구원수·혼인·원가구) · 소득재산(월소득·재산기준) · 복지자격(수급자·차상위) · 중복수급 여부

| ID | 요구사항 | 우선순위 | 완료 |
|---|---|---|---|
| F2-1 | 모든 질문에 사용자가 판단할 수 없는 경우를 위한 `모름` 선택지를 제공한다 | 필수 | ☐ |
| F2-2 | 앞선 답변에 따라 필요한 후속 질문만 노출한다 | 필수 | ☐ |
| F2-3 | 각 질문에 "왜 필요한가"와 확인 방법을 한 문장으로 안내한다 | 필수 | ☐ |
| F2-4 | 소득·재산 기준은 정책 기준연도의 중위소득·자산 상한 표와 가구원 수를 이용해 계산한다 | 필수 | ☐ |
| F2-5 | 정책이 공식 소득인정액을 요구하고 사용자가 이를 모르면 임의 추정하지 않는다 | 필수 | ☐ |
| F2-6 | 입력값은 브라우저에만 저장하고 서버로 전송하지 않는다 | 필수 | ☐ |
| F2-7 | 결과 화면에서 답변을 수정하고 즉시 다시 계산할 수 있다 | 필수 | ☐ |
| F2-8 | 후보 정책들의 추가 질문을 합쳐 중복 질문을 제거한다 | 필수 | ☐ |
| F2-9 | 후보에서 제외된 정책의 전용 질문은 사용자에게 묻지 않는다 | 필수 | ☐ |

> 짧은 설문보다 틀리지 않는 판정이 우선 — 질문 수를 억지로 고정하지 않는다.

## F3. 규칙 기반 자격 판정

### 판정 상태 4종
| 상태 | 기준 | 최대 가능액 반영 |
|---|---|---|
| 예상 적용 | 필수 조건 모두 입력 + 모두 통과 | 포함 |
| 조건 충족 시 가능 | `모름`·증빙필요·미계산 조건 존재 | 최대 조합 후보 |
| 대상 아님 | 필수 조건 중 하나 이상 불충족 | 제외 |
| 신청 불가 | 신청기간 종료·예산소진·대상지역 아님 | 제외 |

| ID | 요구사항 | 우선순위 | 완료 |
|---|---|---|---|
| F3-1 | 판정과 금액 계산은 모두 코드에 정의된 결정론적 규칙으로 수행한다 (AI 미사용) | 필수 | ☐ |
| F3-2 | 같은 입력과 같은 정책 버전은 항상 같은 결과를 반환한다 | 필수 | ☐ |
| F3-3 | 예상 적용 정책에는 통과한 핵심 조건을 표시한다 | 필수 | ☐ |
| F3-4 | 조건 충족 시 가능 정책에는 확인하지 못한 조건과 확인 방법을 표시한다 | 필수 | ☐ |
| F3-5 | 대상 아님 정책에는 최초 탈락 이유뿐 아니라 모든 탈락 이유를 표시한다 | 필수 | ☐ |
| F3-6 | 정책별 신청 기간과 현재 신청 가능 여부를 판정한다 | 필수 | ☐ |
| F3-7 | 중복 제한 정책을 동시에 합산하지 않는다 | 필수 | ☐ |
| F3-8 | 가능한 조합 중 최대 지원 가능액이 가장 큰 유효 조합을 기본 추천한다 | 필수 | ☐ |
| F3-9 | 정책별 공식 출처, 확인 날짜, 적용 기준연도를 표시한다 | 필수 | ☐ |

## F4. 결과와 신청 연결

| ID | 요구사항 | 우선순위 | 완료 |
|---|---|---|---|
| F4-1 | 정책을 예상 적용·조건 충족 시 가능·대상 아님·신청 불가로 나누어 표시한다 | 필수 | ☐ |
| F4-2 | 각 정책에 충족·미충족·확인 필요 요건을 표 형태로 표시한다 | 필수 | ☐ |
| F4-3 | 정책별 지원 형태, 적용 산식, 지급 기간 또는 지급 시점, 총 예상액을 표시한다 | 필수 | ☐ |
| F4-4 | 결과 상단에는 최대 지원 가능액과 최종 예상 주거비 두 금액만 크게 표시한다 | 필수 | ☐ |
| F4-5 | 중복 제한으로 제외한 정책과 선택한 최적 조합을 표시한다 | 필수 | ☐ |
| F4-6 | 계약 시 필요한 선납액과 지원금 지급 시점을 분리해 표시한다 | 필수 | ☐ |
| F4-7 | 월 단위 지원은 계약 당일 필요한 목돈을 줄이지 않는다고 안내한다 | 필수 | ☐ |
| F4-8 | 조건 충족 시 가능 정책이 최대 지원 가능액에 포함되면 해당 미확인 조건을 금액 바로 아래에 표시한다 | 필수 | ☐ |
| F4-9 | 정책별 공식 신청 페이지를 새 탭으로 연결한다 | 필수 | ☐ |
| F4-10 | 결과 기준일과 정책 데이터 확인 날짜를 표시한다 | 필수 | ☐ |
| F4-11 | 결과를 모바일에서 캡처하기 쉬운 한 화면 요약으로 제공한다 | 권장 | ☐ |
