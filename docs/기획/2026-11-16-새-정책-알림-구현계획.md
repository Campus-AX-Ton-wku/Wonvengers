# 새 정책 알림 (웹 푸시) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 팀이 Supabase 에서 정책을 '운영'으로 바꾸면, 1시간 안(서울 9~21시)에 그 정책이 조건에 맞을 수 있는 로그인 사용자에게 웹 푸시 한 통이 간다. 아이폰은 홈 화면에 추가한 Perky 에서 받는다.

**Architecture:** 앱이 빌드 때 `/policies.json` 을 굽고, 기존 AWS 스택(PerkyStack)에 알림 Lambda · EventBridge 매시 규칙 · DynamoDB `perky-push` 표 · API `PUT/DELETE /me/push` 를 더한다. 알림 Lambda 는 배포된 `/policies.json` 과 '이미 알린 정책'을 비교해 새 정책을 고르고, 구독한 사용자마다 `perky-user-data` 의 답으로 앱과 같은 1층 판정(`apps/web/lib/filter.ts`)을 해 `web-push`(VAPID)로 보낸다. 웹은 서비스 워커(`/sw.js`, 알림만)와 내 계정 화면의 알림 칸을 더하고, 로그아웃·탈퇴 때 구독을 끊는다.

**Tech Stack:** Next.js 15 (static export), TypeScript 5.9, Vitest 2 + Testing Library (jsdom), AWS CDK 2 (aws-cdk-lib 2.275, aws-events), AWS SDK v3 3.1161.0, `web-push@3.6.7`, Node.js 22 (Lambda arm64)

**Spec:** `docs/기획/2026-11-16-새-정책-알림-설계.md` (바탕: `docs/기획/2026-11-16-정책-Supabase-읽기-설계.md`, `docs/기획/2026-11-04-카카오-로그인-설계.md`)

## Global Constraints

- 범위는 **새 정책 알림만**. 마감 임박 · 신청 시작 알림, [이미 신청했어요], 오프라인 캐시는 만들지 않는다
- 알림 대상 데이터는 `policies.json`(금액 계산 정책)만. `loan-products.json` 은 보지 않는다
- 받는 사람: 알림을 켠 로그인 사용자 중 저장된 답(`perky-user-data`, `consentVersion` 있음)으로 1층 판정한 결과가 `"가능성 있음"` 또는 `"확인 필요"`. `answers.values.region` 이 없으면 보내지 않는다
- 보내는 시각: 서울 **9시 ~ 21시대**(시 기준 9 ≤ hour ≤ 21). EventBridge `cron(0 0-12 * * ? *)`(UTC). 손으로 실행할 때 `{"force": true}` 면 시간 검사를 건너뛴다
- 이미 마감된(`applicationEnd` < 오늘, 서울 날짜) 새 정책은 보내지 않고 '이미 알림'에만 넣는다. `applicationEnd === null` 이거나 오늘이면 보낸다
- 첫 실행(상태 항목 없음)은 지금 목록을 전부 '이미 알림'으로 적고 **보내지 않는다**
- '이미 알림'은 **보낸 뒤에** 적는다(빠지는 것보다 두 번이 낫다)
- 한 사용자에게 한 회차 한 통. 문구(정확히):
  - 1건 · 가능성 있음 — 제목 `새 지원금이 올라왔어요` · 본문 `{name} — 조건에 맞을 가능성이 있어요` · url `/find/policies/{id}`
  - 1건 · 확인 필요 — 제목 같음 · 본문 `{name} — 받을 수도 있는 지원금이에요. 조건을 확인해 보세요` · url 같음
  - 여러 건 — 제목 `새 지원금 {n}건이 올라왔어요` · 본문 `{첫 정책 name} 외 {n-1}건 — 받을 수 있을지 확인해 보세요` · url `/find/policies`
  - 첫 정책은 '가능성 있음'이 먼저, 같은 등급 안에서는 `/policies.json` 순서. 태그는 모두 `new-policy`
- 알림 문구 · 로그에 사용자 답(소득 · 나이 · 지역)을 넣지 않는다. 로그의 사용자는 `hashUserId`(sha256 앞 16자)만, 알림 Lambda 로그는 숫자 요약만
- 푸시 메시지 TTL 12시간(`43200` 초). 404 · 410 응답이면 그 구독을 지운다
- 구독: 사용자당 기기 **5대**, 넘으면 `updatedAt` 이 가장 오래된 것부터 지운다. 구독 항목 TTL = 마지막 갱신 + 365일(`expiresAt`, 초)
- 구독 본문: `{ endpoint, keys: { p256dh, auth } }` 만(다른 키는 400). endpoint 는 `https://` 로 시작하는 URL, 1000자 이하. p256dh 1~200자 · auth 1~50자, base64url(`[A-Za-z0-9_-]`, 끝 `=` 0~2개). 본문 4096바이트 넘으면 413
- 사용자 ID 는 토큰의 `sub` 에서만(기존 규칙). 상태 항목 키는 `userId = "__state__"`, `deviceId = "announced"`
- VAPID 비밀 키는 SSM SecureString `/perky/push/vapid-private-key`, 공개 키는 SSM String `/perky/push/vapid-public-key` + Vercel `NEXT_PUBLIC_VAPID_PUBLIC_KEY`. subject `https://wonvengers.vercel.app`. 저장소·코드·커밋 메시지에 비밀 키를 쓰지 않는다
- 알림 Lambda 가 읽는 목록: `https://wonvengers.vercel.app/policies.json`(배포된 정식 앱)
- `NEXT_PUBLIC_VAPID_PUBLIC_KEY` 가 없거나 로그인을 쓸 수 없는 빌드면 알림 칸을 그리지 않는다 — 테스트 기본 상태
- 서비스 워커는 `push` · `notificationclick` · `install`(skipWaiting) · `activate`(clients.claim)만. **`fetch` 처리기를 두지 않는다**
- 리전 `ap-northeast-2` 하나, 계정 `448842988711`. **AWS Organizations · IAM Identity Center 를 켜지 않는다**
- 의존성 정확히 고정: api `web-push@3.6.7`, `@types/web-push@3.6.4`(나머지는 기존 고정 그대로)
- 화면 문구는 한국어 해요체. 터치 타깃 44px 이상(`Button` 의 `md`·`screen`·`lg`)
- `apps/web/app/result/BenefitResultCard.tsx`, `apps/web/lib/benefit-result.ts`, `apps/web/app/result/ResultState.tsx` 는 건드리지 않는다
- 공통 컴포넌트는 `@/app/components` 로만 import
- push · PR · `cdk deploy` · AWS 자원 생성/삭제 · Vercel 설정은 사용자가 요청할 때만. **⛔ 표시 단계는 사용자에게 확인을 받은 뒤에만 실행한다.** 그 밖에는 로컬 커밋만

```ts
// apps/api/test/notifier-plan.test.ts
import { describe, expect, it } from "vitest";
import { composeMessage, isSendingHour, kst, matchPolicies, selectNewPolicies, type Match } from "../src/notifier/plan";
import type { DiscoveryAnswers } from "../../web/lib/types";
import { policy } from "./fixtures";

const answers = (over: Partial<DiscoveryAnswers> = {}): DiscoveryAnswers => ({
  birthDate: "2002-03-14",
  region: "전북특별자치도 익산시",
  status: "대학생",
  incomeBracket: 1,
  housingType: "월세",
  ...over,
});

describe("서울 시각", () => {
  it("UTC 를 서울(+9)로 — 날짜와 시", () => {
    expect(kst(new Date("2026-11-16T15:30:00Z"))).toEqual({ date: "2026-11-17", hour: 0 });
    expect(kst(new Date("2026-11-16T00:00:00Z"))).toEqual({ date: "2026-11-16", hour: 9 });
  });

  it("보내는 시간은 서울 9시대 ~ 21시대", () => {
    expect(isSendingHour(new Date("2026-11-15T23:59:00Z"))).toBe(false); // 08:59
    expect(isSendingHour(new Date("2026-11-16T00:00:00Z"))).toBe(true); // 09:00
    expect(isSendingHour(new Date("2026-11-16T12:00:00Z"))).toBe(true); // 21:00
    expect(isSendingHour(new Date("2026-11-16T13:00:00Z"))).toBe(false); // 22:00
  });
});

describe("selectNewPolicies", () => {
  const a = policy({ id: "a" });
  const b = policy({ id: "b" });
  const closed = policy({ id: "closed", applicationEnd: "2026-11-15" });
  const lastDay = policy({ id: "last-day", applicationEnd: "2026-11-16" });

  it("이미 알린 것은 빼고 들어온 순서대로", () => {
    expect(selectNewPolicies([a, b], new Set(["a"]), "2026-11-16")).toEqual({ toSend: [b], toMark: ["b"] });
  });

  it("마감된 새 정책은 보내지 않고 '이미 알림'에만 넣는다 — 마감일 당일은 보낸다", () => {
    const out = selectNewPolicies([closed, lastDay], new Set(), "2026-11-16");
    expect(out.toSend.map((p) => p.id)).toEqual(["last-day"]);
    expect(out.toMark).toEqual(["closed", "last-day"]);
  });

  it("새 것이 없으면 둘 다 빈 배열", () => {
    expect(selectNewPolicies([a], new Set(["a"]), "2026-11-16")).toEqual({ toSend: [], toMark: [] });
  });
});

describe("matchPolicies — 앱과 같은 1층 판정", () => {

    expect(matchPolicies(answers({ region: null }), [policy({ id: "a" })], "2026-11-16")).toBeNull();
```

```ts
/** 보내는 시간: 서울 9시대 ~ 21시대 */
export const SEND_HOURS = { first: 9, last: 21 } as const;

/** 서울(UTC+9, 서머타임 없음)의 날짜(YYYY-MM-DD)와 시 */
export function kst(now: Date): { date: string; hour: number } {
  const shifted = new Date(now.getTime() + 9 * 3600_000);
  return { date: shifted.toISOString().slice(0, 10), hour: shifted.getUTCHours() };
}

export function isSendingHour(now: Date): boolean {
  const { hour } = kst(now);
  return hour >= SEND_HOURS.first && hour <= SEND_HOURS.last;
}

/**
 * 이미 알린 목록에 없는 정책. 마감된 것(applicationEnd < 오늘)은 보내지 않지만 toMark 에는 넣는다 —
 * 그래야 다음 회차에 다시 '새 정책'으로 잡히지 않는다.
 */
export function selectNewPolicies(
  published: PolicyMeta[],
  announced: ReadonlySet<string>,
  today: string
): { toSend: PolicyMeta[]; toMark: string[] } {
  const fresh = published.filter((p) => !announced.has(p.id));
  return {
    toSend: fresh.filter((p) => p.applicationEnd === null || p.applicationEnd >= today),
    toMark: fresh.map((p) => p.id),
  };
}

export type MatchTag = "가능성 있음" | "확인 필요";
export interface Match {
  policy: PolicyMeta;
  tag: MatchTag;
}

/**
 * 저장된 답으로 1층 판정. 지역을 답하지 않았으면 null — 알리지 않는다(11/08 결정).
 * '해당 없음'은 빼고, '가능성 있음'을 앞에 둔다(같은 등급은 들어온 순서).
 */
export function matchPolicies(answers: DiscoveryAnswers, policies: PolicyMeta[], today: string): Match[] | null {
  if (!answers.region) return null;
  const resolved = resolveAnswers(answers, today);
  const matches: Match[] = [];
  for (const policy of policies) {
    const { tag } = tagPolicy(policy, resolved);
    if (tag === "가능성 있음" || tag === "확인 필요") matches.push({ policy, tag });
  }
  return [...matches.filter((m) => m.tag === "가능성 있음"), ...matches.filter((m) => m.tag === "확인 필요")];
}

export interface PushMessage {
  title: string;
  body: string;
  url: string;
  tag: string;
}

const TAG = "new-policy";

/** 잠금 화면에 보이므로 정책 이름만 — 소득 · 나이 같은 답은 넣지 않는다. */
export function composeMessage(matches: Match[]): PushMessage {
  if (matches.length === 0) throw new Error("composeMessage: no matches");
  const [first] = matches;
  if (matches.length === 1) {
    return {
      title: "새 지원금이 올라왔어요",
      body:
        first.tag === "가능성 있음"
          ? `${first.policy.name} — 조건에 맞을 가능성이 있어요`
          : `${first.policy.name} — 받을 수도 있는 지원금이에요. 조건을 확인해 보세요`,
      url: `/find/policies/${first.policy.id}`,
      tag: TAG,
    };
  }
  return {
    title: `새 지원금 ${matches.length}건이 올라왔어요`,
    body: `${first.policy.name} 외 ${matches.length - 1}건 — 받을 수 있을지 확인해 보세요`,
    url: "/find/policies",
    tag: TAG,
  };
}
```

```ts
// apps/web/lib/push-subscription.ts
import type { Validation } from "./user-data";

/**
 * 알림 구독 본문 — 웹(lib/push.ts · lib/remote.ts)과 API(apps/api)가 함께 쓰는 단독 출처
 * (docs/기획/2026-11-16-새-정책-알림-설계.md "API"). user-data.ts 처럼 타입 말고는 아무것도 import 하지 않고,
 * 브라우저 API 도 Node API 도 쓰지 않는다. 오류에는 경로만 담는다(값은 담지 않는다).
 */
export interface PushSubscriptionBody {
  endpoint: string;
  keys: { p256dh: string; auth: string };
}

export const MAX_PUSH_BODY_BYTES = 4096;
export const MAX_ENDPOINT_LENGTH = 1000;

const BASE64URL = /^[A-Za-z0-9_-]+={0,2}$/;

const isPlainObject = (v: unknown): v is Record<string, unknown> =>
  typeof v === "object" && v !== null && !Array.isArray(v);

function unknownKey(obj: Record<string, unknown>, allowed: readonly string[], prefix = ""): string | null {
  const extra = Object.keys(obj).find((k) => !allowed.includes(k));
  return extra === undefined ? null : `${prefix}${extra}`;
}

function isEndpoint(v: unknown): v is string {
  if (typeof v !== "string" || !v.startsWith("https://") || v.length > MAX_ENDPOINT_LENGTH) return false;
  try {
    return new URL(v).hostname !== "";
  } catch {
    return false;
  }
}

const isKey = (v: unknown, max: number): v is string =>
  typeof v === "string" && v.length >= 1 && v.length <= max && BASE64URL.test(v);

export function validatePushSubscription(input: unknown): Validation<PushSubscriptionBody> {
  if (!isPlainObject(input)) return { ok: false, error: "(root)" };
  const extra = unknownKey(input, ["endpoint", "keys"]);
  if (extra) return { ok: false, error: extra };
  if (!isEndpoint(input.endpoint)) return { ok: false, error: "endpoint" };
  const keys = input.keys;
  if (!isPlainObject(keys)) return { ok: false, error: "keys" };
  const extraKey = unknownKey(keys, ["p256dh", "auth"], "keys.");
  if (extraKey) return { ok: false, error: extraKey };
  if (!isKey(keys.p256dh, 200)) return { ok: false, error: "keys.p256dh" };
  if (!isKey(keys.auth, 50)) return { ok: false, error: "keys.auth" };
  return { ok: true, value: { endpoint: input.endpoint, keys: { p256dh: keys.p256dh, auth: keys.auth } } };
}

export function validatePushEndpoint(input: unknown): Validation<{ endpoint: string }> {
  if (!isPlainObject(input)) return { ok: false, error: "(root)" };
  const extra = unknownKey(input, ["endpoint"]);
  if (extra) return { ok: false, error: extra };
  if (!isEndpoint(input.endpoint)) return { ok: false, error: "endpoint" };
  return { ok: true, value: { endpoint: input.endpoint } };
}
```

```ts
// apps/api/src/push-store.ts
import { createHash } from "node:crypto";
import type { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import {
  DeleteCommand,
  DynamoDBDocumentClient,
  GetCommand,
  PutCommand,
  QueryCommand,
  ScanCommand,
  UpdateCommand,
} from "@aws-sdk/lib-dynamodb";
import type { PushSubscriptionBody } from "../../web/lib/push-subscription";

/**
 * 표 perky-push (docs/기획/2026-11-16-새-정책-알림-설계.md "DynamoDB perky-push").
 * 파티션 userId(Cognito sub) + 정렬 deviceId(구독 주소 해시). 사용자 × 기기마다 한 항목.
 * 알림 Lambda 의 '이미 알린 정책'은 userId = "__state__" 인 항목 하나에 둔다(sub 는 UUID 라 겹치지 않는다).
 */
export const STATE_USER = "__state__";
export const STATE_DEVICE = "announced";
export const MAX_DEVICES = 5;
/** 마지막 갱신 후 1년이 지나면 DynamoDB TTL 이 지운다. 계정 화면을 열 때마다 갱신된다. */
export const PUSH_TTL_SECONDS = 365 * 24 * 60 * 60;

export function deviceIdOf(endpoint: string): string {
  return createHash("sha256").update(endpoint).digest("hex").slice(0, 32);
}

export interface StoredDevice extends PushSubscriptionBody {
  userId: string;
  deviceId: string;
  updatedAt: string;
}

export interface PushStore {
  /** 켜기 · 갱신. 다른 기기가 이미 MAX_DEVICES 대면 가장 오래된 것부터 지운다. */
  put(userId: string, sub: PushSubscriptionBody, now: Date): Promise<void>;
  /** 끄기 — 이 기기 하나. 없어도 조용히. */
  delete(userId: string, endpoint: string): Promise<void>;
  /** 탈퇴 — 그 사용자의 기기 전부. */
  deleteAll(userId: string): Promise<void>;
  /** 알림 Lambda — 모든 구독(상태 항목 제외). */
  listDevices(): Promise<StoredDevice[]>;
  /** 알림 Lambda — 끊긴 구독(404 · 410) 정리. */
  deleteDevice(userId: string, deviceId: string): Promise<void>;
  /** 이미 알린 정책 id. 상태 항목이 없으면(첫 실행) null. */
  getAnnounced(): Promise<Set<string> | null>;
  saveAnnounced(ids: ReadonlySet<string>, now: Date): Promise<void>;
}

export class DynamoPushStore implements PushStore {
  private readonly doc: DynamoDBDocumentClient;

  constructor(client: DynamoDBClient, private readonly tableName: string) {
    this.doc = DynamoDBDocumentClient.from(client, { marshallOptions: { removeUndefinedValues: true } });
  }

  private async devicesOf(userId: string): Promise<{ deviceId: string; updatedAt?: string }[]> {
    const out = await this.doc.send(
      new QueryCommand({
        TableName: this.tableName,
        KeyConditionExpression: "userId = :u",
        ExpressionAttributeValues: { ":u": userId },
        ProjectionExpression: "deviceId, updatedAt",
      })
    );
    return (out.Items ?? []) as { deviceId: string; updatedAt?: string }[];
  }

  async put(userId: string, sub: PushSubscriptionBody, now: Date): Promise<void> {
    const deviceId = deviceIdOf(sub.endpoint);
    const others = (await this.devicesOf(userId)).filter((d) => d.deviceId !== deviceId);
    const overflow = others.length - (MAX_DEVICES - 1);
    if (overflow > 0) {
      const oldest = [...others].sort((a, b) => (a.updatedAt ?? "").localeCompare(b.updatedAt ?? "")).slice(0, overflow);
      for (const d of oldest) await this.deleteDevice(userId, d.deviceId);
    }
    const iso = now.toISOString();
    await this.doc.send(
      new UpdateCommand({
        TableName: this.tableName,
        Key: { userId, deviceId },
        UpdateExpression:
          "SET #endpoint = :endpoint, #p256dh = :p256dh, #auth = :auth, #updatedAt = :now, #expiresAt = :expiresAt, #createdAt = if_not_exists(#createdAt, :now)",
        ExpressionAttributeNames: {
          "#endpoint": "endpoint",
          "#p256dh": "p256dh",
          "#auth": "auth",
          "#updatedAt": "updatedAt",
          "#expiresAt": "expiresAt",
          "#createdAt": "createdAt",
        },
        ExpressionAttributeValues: {
          ":endpoint": sub.endpoint,
          ":p256dh": sub.keys.p256dh,
          ":auth": sub.keys.auth,
          ":now": iso,
          ":expiresAt": Math.floor(now.getTime() / 1000) + PUSH_TTL_SECONDS,
        },
      })
    );
  }

  async delete(userId: string, endpoint: string): Promise<void> {
    await this.deleteDevice(userId, deviceIdOf(endpoint));
  }

  async deleteAll(userId: string): Promise<void> {
    for (const d of await this.devicesOf(userId)) await this.deleteDevice(userId, d.deviceId);
  }

  async deleteDevice(userId: string, deviceId: string): Promise<void> {
    await this.doc.send(new DeleteCommand({ TableName: this.tableName, Key: { userId, deviceId } }));
  }

  async listDevices(): Promise<StoredDevice[]> {
    const devices: StoredDevice[] = [];
    let start: Record<string, unknown> | undefined;
    do {
      const out = await this.doc.send(
        new ScanCommand({
          TableName: this.tableName,
          FilterExpression: "userId <> :state",
          ExpressionAttributeValues: { ":state": STATE_USER },
          ...(start ? { ExclusiveStartKey: start } : {}),
        })
      );
      for (const item of out.Items ?? []) {
        devices.push({
          userId: String(item.userId),
          deviceId: String(item.deviceId),
          endpoint: String(item.endpoint),
          keys: { p256dh: String(item.p256dh), auth: String(item.auth) },
          updatedAt: String(item.updatedAt),
        });
      }
      start = out.LastEvaluatedKey;
    } while (start);
    return devices;
  }

  async getAnnounced(): Promise<Set<string> | null> {
    const out = await this.doc.send(
      new GetCommand({ TableName: this.tableName, Key: { userId: STATE_USER, deviceId: STATE_DEVICE }, ConsistentRead: true })
    );
    if (!out.Item) return null;
    const ids = out.Item.policyIds;
    return new Set(Array.isArray(ids) ? ids.map(String) : []);
  }

  async saveAnnounced(ids: ReadonlySet<string>, now: Date): Promise<void> {
    await this.doc.send(
      new PutCommand({
        TableName: this.tableName,
        // 문자열 집합(SS)은 비어 있을 수 없어서 배열(L)로 둔다
        Item: { userId: STATE_USER, deviceId: STATE_DEVICE, policyIds: [...ids].sort(), updatedAt: now.toISOString() },
      })
    );
  }
}
```

```ts
function readJson(event: ApiEvent, maxBytes: number): { ok: true; value: unknown } | { ok: false; result: ApiResult } {
  const bytes = bodyBytes(event);
  if (bytes.length > maxBytes) return { ok: false, result: json(413, { error: "too_large" }) };
  try {
    return { ok: true, value: JSON.parse(bytes.toString("utf8")) };
  } catch {
    return { ok: false, result: json(400, { error: "invalid_json" }) };
  }
}

/** 알림 켜기 · 갱신 (설계 "API"). 사용자는 토큰 sub 로만 정한다. */
async function putPush(sub: string, event: ApiEvent, deps: Deps): Promise<ApiResult> {
  const body = readJson(event, MAX_PUSH_BODY_BYTES);
```

```ts
/**
 * 배포된 정식 앱의 /policies.json (apps/web/app/policies.json/route.ts). DB 가 아니라 앱에 실린 목록을 본다 —

 */
export async function fetchPublishedPolicies(url: string, fetchImpl: typeof fetch = fetch): Promise<PolicyMeta[]> {
  const res = await fetchImpl(url, { signal: AbortSignal.timeout(10_000), headers: { "cache-control": "no-cache" } });
  if (!res.ok) throw new Error(`policies.json ${res.status}`);
  const body: unknown = await res.json();
  if (!Array.isArray(body)) throw new Error("policies.json is not an array");
  for (const item of body) {
    const p = item as Partial<PolicyMeta>;
    if (typeof p?.id !== "string" || typeof p.name !== "string" || typeof p.discovery !== "object" || p.discovery === null) {
      throw new Error("policies.json has a malformed item");
    }
  }
  return body as PolicyMeta[];
}
```

```ts
  subject: string;
  publicKey: string;
  privateKey: string;
}

/** web-push 의 쓰는 부분만 — 테스트에서 가짜로 바꾼다. */
export interface WebPushLike {
  sendNotification(
    subscription: { endpoint: string; keys: { p256dh: string; auth: string } },
    payload: string,
    options: { TTL: number; vapidDetails: VapidDetails }
  ): Promise<unknown>;
}

export function createSender(lib: WebPushLike, vapid: VapidDetails): Sender {
  return async (device, message) => {

      await lib.sendNotification({ endpoint: device.endpoint, keys: device.keys }, JSON.stringify(message), {
        TTL: MESSAGE_TTL_SECONDS,
        vapidDetails: vapid,
      });
      return "sent";
```

```ts
// apps/api/src/notifier/run.ts
import type { PolicyMeta } from "../../../web/lib/types";
import type { PushStore, StoredDevice } from "../push-store";
import type { UserDataStore } from "../store";
import { composeMessage, isSendingHour, kst, matchPolicies, selectNewPolicies } from "./plan";
import type { Sender } from "./sender";

/** 한 회차 (docs/기획/2026-11-16-새-정책-알림-설계.md "알림 Lambda" 1~9). 저장소 · 네트워크는 deps 로 받는다. */
export interface NotifierDeps {
  push: Pick<PushStore, "listDevices" | "deleteDevice" | "getAnnounced" | "saveAnnounced">;
  users: Pick<UserDataStore, "get">;
  fetchPolicies(): Promise<PolicyMeta[]>;
  send: Sender;
  now(): Date;
}

export interface RunSummary {
  outcome: "skipped-hours" | "fetch-failed" | "initialized" | "no-new" | "sent";
  newPolicies: number;
  recipients: number;
  devicesSent: number;
  devicesFailed: number;
  devicesRemoved: number;
}

export async function runNotifier(deps: NotifierDeps, { force = false }: { force?: boolean } = {}): Promise<RunSummary> {
  const now = deps.now();
  const summary: RunSummary = {
    outcome: "no-new",
    newPolicies: 0,
    recipients: 0,
    devicesSent: 0,
    devicesFailed: 0,
    devicesRemoved: 0,
  };
  if (!force && !isSendingHour(now)) return { ...summary, outcome: "skipped-hours" };

  let published: PolicyMeta[];
  try {
    published = await deps.fetchPolicies();
  } catch {
    return { ...summary, outcome: "fetch-failed" };
  }

  const announced = await deps.push.getAnnounced();
  if (announced === null) {
    // 첫 실행: 지금 있는 정책을 한꺼번에 알리지 않는다
    await deps.push.saveAnnounced(new Set(published.map((p) => p.id)), now);
    return { ...summary, outcome: "initialized" };
  }

  const today = kst(now).date;
  const { toSend, toMark } = selectNewPolicies(published, announced, today);
  if (toMark.length === 0) return summary;
  summary.newPolicies = toSend.length;

  if (toSend.length > 0) {
    const byUser = new Map<string, StoredDevice[]>();
    for (const d of await deps.push.listDevices()) byUser.set(d.userId, [...(byUser.get(d.userId) ?? []), d]);

    for (const [userId, devices] of byUser) {
      try {
        const item = await deps.users.get(userId);
        if (!item || !item.data.consentVersion) continue;
        const matches = matchPolicies(item.data.answers.values, toSend, today);
        if (!matches || matches.length === 0) continue;
        summary.recipients += 1;
        const message = composeMessage(matches);
        for (const device of devices) {
          const outcome = await deps.send(device, message);
          if (outcome === "sent") summary.devicesSent += 1;
          else if (outcome === "gone") {
            await deps.push.deleteDevice(userId, device.deviceId);
            summary.devicesRemoved += 1;
          } else summary.devicesFailed += 1;
        }
      } catch {
        // 이 사용자만 건너뛴다 — 나머지 사용자에게는 보낸다
        summary.devicesFailed += devices.length;
      }
    }
  }

  // 보낸 '뒤에' 적는다 — 그 사이에 멈추면 다음 회차에 다시 보낸다(빠지는 것보다 낫다)
  await deps.push.saveAnnounced(new Set([...announced, ...toMark]), now);
  return { ...summary, outcome: toSend.length > 0 ? "sent" : "no-new" };
}
```

> `noconsent` 테스트는 `consentVersion` 을 빈 글자로 둔다. 실제 저장 항목은 서버 검사(`validatePutRequest`)를 지나 항상 버전이 있지만, 알림은 동의 없이 보내지 않는다는 규칙을 코드로 남긴다.

```ts
import webpush from "web-push";
import { DynamoPushStore } from "../push-store";

import { runNotifier, type NotifierDeps, type RunSummary } from "./run";

/**
 * 알림 Lambda 진입점. EventBridge 가 매시 정각(서울 9~21시) 빈 이벤트로 부른다.
 * 시연 · 시험 때 손으로: aws lambda invoke --payload '{"force":true}' (설계 "3. 시연 절차").
 * 환경변수는 infra/lib/perky-stack.ts 가 넣는다. 비밀 키는 SSM 에서 읽는다.
 */
function required(name: string): string {
  const value = process.env[name];
  if (!value) throw new Error(`${name} is not set`);
  return value;
}

async function parameter(ssm: SSMClient, name: string): Promise<string> {
  const out = await ssm.send(new GetParameterCommand({ Name: name, WithDecryption: true }));
  const value = out.Parameter?.Value;
  if (!value) throw new Error(`SSM ${name} is empty`);
  return value;
}

let deps: NotifierDeps | null = null;

async function liveDeps(): Promise<NotifierDeps> {
  const dynamo = new DynamoDBClient({});
  const ssm = new SSMClient({});
  const [publicKey, privateKey] = await Promise.all([
    parameter(ssm, required("VAPID_PUBLIC_KEY_PARAM")),
    parameter(ssm, required("VAPID_PRIVATE_KEY_PARAM")),
  ]);
  const policiesUrl = required("POLICIES_URL");
  return {
    push: new DynamoPushStore(dynamo, required("PUSH_TABLE_NAME")),
    users: new DynamoUserDataStore(dynamo, required("TABLE_NAME")),
    fetchPolicies: () => fetchPublishedPolicies(policiesUrl),
    send: createSender(webpush, { subject: required("VAPID_SUBJECT"), publicKey, privateKey }),
    now: () => new Date(),
  };
}

export async function handler(event?: { force?: unknown }): Promise<RunSummary> {
  deps ??= await liveDeps();
  const summary = await runNotifier(deps, { force: event?.force === true });
  // 숫자 요약만 남긴다 — 사용자 id · 답 · 구독 주소는 남기지 않는다
```

```ts
// apps/web/lib/push.ts
import { authConfig } from "./auth";
import type { PushSubscriptionBody } from "./push-subscription";
import { deletePushRemote, putPushRemote } from "./remote";

/**
 * 이 기기의 알림 구독 (docs/기획/2026-11-16-새-정책-알림-설계.md "lib/push.ts").
 * 부르는 쪽: 내 계정 화면(app/account/PushSettings.tsx), 로그아웃 · 탈퇴(lib/sync.ts).
 */
export const SW_PATH = "/sw.js";

/** Next 는 process.env.NEXT_PUBLIC_* 를 빌드 때 글자 그대로 바꿔 넣는다 — 이 줄의 모양을 바꾸지 말 것. */
export function vapidPublicKey(): string | null {
  return process.env.NEXT_PUBLIC_VAPID_PUBLIC_KEY || null;
}

/** 알림 칸을 그릴지 — 로그인을 쓸 수 있고 공개 키가 있을 때만 */
export function isPushConfigured(): boolean {
  return authConfig() !== null && vapidPublicKey() !== null;
}

export type PushSupport = "unsupported" | "needs-home-screen" | "ready";

type NavigatorWithStandalone = Navigator & { standalone?: boolean };

function isIos(nav: Navigator): boolean {
  return /iPad|iPhone|iPod/.test(nav.userAgent) || (nav.platform === "MacIntel" && nav.maxTouchPoints > 1);
}

function isStandalone(win: Window): boolean {
  return win.matchMedia?.("(display-mode: standalone)").matches === true || (win.navigator as NavigatorWithStandalone).standalone === true;
}

/** 아이폰은 홈 화면에 추가한 앱(iOS 16.4+)에서만 웹 푸시를 받는다. */
export function pushSupport(win: Window = window): PushSupport {
  const nav = win.navigator;
  if (isIos(nav) && !isStandalone(win)) return "needs-home-screen";
  const capable = "serviceWorker" in nav && "PushManager" in win && "Notification" in win;
  return capable ? "ready" : "unsupported";
}

export type PushState = "on" | "off" | "denied";

async function currentSubscription(): Promise<PushSubscription | null> {
  if (typeof navigator === "undefined" || !navigator.serviceWorker) return null;
  const registration = await navigator.serviceWorker.getRegistration("/");
  return (await registration?.pushManager.getSubscription()) ?? null;
}

export async function pushState(): Promise<PushState> {
  if (Notification.permission === "denied") return "denied";
  const sub = await currentSubscription();
  return sub && Notification.permission === "granted" ? "on" : "off";
}

/** 서버에 보낼 모양 — endpoint 와 keys 만(expirationTime 은 서버가 거부한다). */
function toBody(sub: PushSubscription): PushSubscriptionBody {
  const json = sub.toJSON();
  const p256dh = json.keys?.p256dh;
  const auth = json.keys?.auth;
  if (!json.endpoint || !p256dh || !auth) throw new Error("push subscription has no keys");
  return { endpoint: json.endpoint, keys: { p256dh, auth } };
}

function base64UrlToBytes(base64url: string): Uint8Array {
  const padded = base64url.replace(/-/g, "+").replace(/_/g, "/").padEnd(Math.ceil(base64url.length / 4) * 4, "=");
  const raw = atob(padded);
  return Uint8Array.from(raw, (c) => c.charCodeAt(0));
}

/**
 * [알림 켜기]. 버튼 클릭 안에서 부른다 — 아이폰은 사용자 동작 직후에만 권한을 물을 수 있어서
 * 권한 요청을 맨 먼저 한다(워커 등록보다 앞).
 */
export async function enablePush(): Promise<PushState> {
  const key = vapidPublicKey();
  if (!key) throw new Error("push is not configured");
  const permission = await Notification.requestPermission();
  if (permission !== "granted") return permission === "denied" ? "denied" : "off";
  await navigator.serviceWorker.register(SW_PATH, { scope: "/" });
  const registration = await navigator.serviceWorker.ready;
  const sub =
    (await registration.pushManager.getSubscription()) ??
    (await registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: base64UrlToBytes(key) }));
  try {
    await putPushRemote(toBody(sub));
  } catch (err) {
    // 서버가 모르는 구독을 남기지 않는다 — '켜짐'인데 알림이 안 오는 일을 막는다
    await sub.unsubscribe().catch(() => false);
    throw err;
  }
  return "on";
}

/** [알림 끄기]. 서버에서 지우지 못해도 기기 구독은 끊는다(다음 발송 때 410 으로 서버에서도 지워진다). */
export async function disablePush(): Promise<void> {
  const sub = await currentSubscription();
  if (!sub) return;
  await deletePushRemote(sub.endpoint).catch(() => undefined);
  await sub.unsubscribe().catch(() => false);
}

/** 계정 화면을 열 때 — 구독 중이면 서버에 다시 알려 보관 기간을 늘린다. 실패해도 조용히. */
export async function refreshPush(): Promise<void> {
  const sub = await currentSubscription().catch(() => null);
  if (!sub) return;
  await putPushRemote(toBody(sub)).catch(() => undefined);
}

/** 로그아웃 — 최대 timeoutMs 만 기다리고 무엇이 실패해도 던지지 않는다. */
export async function disablePushQuietly(timeoutMs = 3000): Promise<void> {
  if (typeof navigator === "undefined" || !navigator.serviceWorker) return;
  let timer: ReturnType<typeof setTimeout> | undefined;
  await Promise.race([
    disablePush().catch(() => undefined),
    new Promise<void>((resolve) => {
      timer = setTimeout(resolve, timeoutMs);
    }),
  ]);
  clearTimeout(timer);
}

/** 탈퇴 — 서버는 이미 그 사용자의 구독을 모두 지웠다. 이 기기 구독만 끊는다. */
export async function unsubscribeThisDevice(): Promise<void> {
  const sub = await currentSubscription().catch(() => null);
  await sub?.unsubscribe().catch(() => false);
}
```

```tsx
  const [busy, setBusy] = useState(false);
  const [failed, setFailed] = useState(false);

  useEffect(() => {
    let alive = true;
    (async () => {
      const support = pushSupport();
      if (support !== "ready") return setView(support);
      const sub = storedSub();
      if (!sub || !hasConsent(sub)) return setView("no-consent");

      alive = false;
    };

    setBusy(true);
    setFailed(false);
    try {
      setView(await enablePush());
    } catch {
      setFailed(true);
      setView("off");
    } finally {
      setBusy(false);
    }
  }

  async function turnOff() {
    setBusy(true);
    try {
      await disablePush();
    } finally {
      setView("off");
      setBusy(false);
    }
  }

  const note = NOTE[view];
  return (
    <section aria-labelledby="push-heading" className="flex flex-col gap-2">
      <h2 id="push-heading" className="text-base font-bold text-ink-900">
        알림

          </p>

            {busy ? "켜는 중…" : "알림 켜기"}
          </Button>
        </>
      )}
      {view === "on" && (
        <div className="flex items-center justify-between gap-3">
          <p className="text-sm font-bold text-ink-900">알림 켜짐</p>
```
