# 익산 담당 부서 전화 확인표

> 2026-11-03 익산 신뢰데이터 작업에서 앱에 넣은 연락처를 실제 전화로 확인하기 위한 표다.
> 익산 사용자에게 보이는 항목(전국·전북·익산 범위 정책 6건, 대출 7건, 주택공급 1건)과
> 상담 창구 4곳이 대상이다. 번호는 모두 원문(공고·기관 페이지)에 적힌 값이고 통화로 확인한 적은 없다.
> 관련 항목: [전국화 Phase 1 확인목록](2026-09-02-전국화Phase1-확인목록.md) 19~23번.
>
> **2026-11-13 통화 결과 반영** — 박민준이 건 통화를 노찬영이 옮겨 적었다. 표에 없던 질문은 `(11/13 추가)`로 덧붙였다.
> 담당자 출장으로 못 물은 것(익산형 연세·인원, 지역정착 485명, 이사비 마감 날짜)은 11/16(월)에 다시 건다.

## 통화 요령

1. 먼저 자기소개: "원광대 학생 팀입니다. 청년 주거 안내 앱을 만들고 있어 확인차 전화드렸습니다."
2. 공식 답변이 아니면 "담당자 개인 의견"이라고 답 칸에 적는다.
3. 모르겠다고 하면 "모름"이라고 적는다 — 추정해서 적지 않는다.

답을 적은 뒤 PR 담당자에게 알려 주세요 — `phoneCheckedAt`·`nextRound` 에 반영합니다.

같은 번호는 한 통화로 묶었다. 항목 id 는 표의 첫 칸에만 적었고, 빈 칸은 바로 위 id 의 질문이다.
번호가 틀렸다고 하면 바른 번호를 답에 적는다.
