# 청약 공고 상세 페이지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 익산 청약 공고 한 건의 세부(일정 · 단지별 금액 · 주택형별 공급금액 · 문의)를 `/housing/notice?id=…` 한 장으로 보여 준다.

**Architecture:** 빌드 스크립트(`scripts/notices/build.mjs`)가 공고마다 `detail` 을 만들어 `data/notices.json` 에 함께 굽는다(마이홈 단지 줄 합치기, 청약홈 주택형 API 한 번 더). 화면은 정적 export 라 물음표 주소 한 장이 스냅숏에서 공고를 찾아 그린다. 알림 서버가 쓰는 `lib/notices.ts` 는 건드리지 않고 새 `lib/notice-detail.ts` 에 타입을 둔다.

**Tech Stack:** Next.js 15 (static export) · TypeScript · Tailwind 4 · Vitest + Testing Library

**Spec:** `docs/기획/2026-11-22-청약-공고-설계.md` §7

## Global Constraints

- 자격은 판정하지 않는다. 확인 못 한 값은 보여 주지 않는다(F0-5)
- 마이홈 금액은 **원**, 모두 '가장 낮은 조건' — 화면에 "가장 낮은 조건 기준이에요." 를 단다
- 청약홈 `LTTOT_TOP_AMOUNT` 는 **만원** → 원으로 바꿔 둔다. 표 머리는 "공급금액(최고가 기준)"
- 무순위 · 잔여의 주택형 API 는 부르지 않는다(단위 미대조)
- 주택형 호출 실패 → 그 공고의 표만 없음(`houseTypes: null`). 빌드 · 목록 · 나머지 상세는 그대로
- `lib/notices.ts` 는 바꾸지 않는다('AWS 배포' 경로)
- 키(`BOJOGEUM_KEY`)는 출력 · 오류 문구에 싣지 않는다
- 검증: `node node_modules/typescript/bin/tsc --noEmit` · `node node_modules/vitest/vitest.mjs run` · `npm run build` (apps/web)

```js
const won = (v) => (Number.isFinite(Number(v)) && Number(v) > 0 ? Number(v) : null);
const range = (label, s, e) => {
  const start = ymd(s);
  if (!start) return null;
  const end = ymd(e);
  return { label, start, end: end && end !== start ? end : null };
};

/** "0638581118" → "063-858-1118". 모르는 모양은 null — 틀린 번호를 걸게 하지 않는다 */
export function telLabel(raw) {
  const d = String(raw ?? "").replace(/\D/g, "");
  const m = /^(02)(\d{3,4})(\d{4})$/.exec(d) ?? /^(0\d{2})(\d{3,4})(\d{4})$/.exec(d) ?? /^(1\d{3})(\d{4})$/.exec(d);
  return m ? m.slice(1).join("-") : null;
}
```

`fromMyhome` returns `{ ...기존, detail: myhomeDetail(row, kind) }`; `fromApplyhome` returns `{ ...기존, detail: applyhomeDetail(row) }`.

`mergeNotices` keeps a `Map` of kept notices; a repeated id appends complexes not already present (same `name` + `address`):

```js
export function mergeNotices(list, today) {
  const replaced = new Set(list.map((n) => n?.replaces).filter(Boolean));
  const kept = new Map();
  for (const n of list) {
    if (!n || replaced.has(n.id)) continue;
    if (!n.applyStart && !n.applyEnd) continue;
    if (n.applyEnd && n.applyEnd < today) continue;
    const first = kept.get(n.id);
    if (first) {
      // 마이홈은 단지마다 한 줄 — 단지를 모은다(설계 §7.2)
      for (const c of n.detail?.complexes ?? [])
        if (!first.detail.complexes.some((x) => x.name === c.name && x.address === c.address)) first.detail.complexes.push(c);
      continue;
    }
    const { replaces: _replaces, ...notice } = n;
    kept.set(n.id, notice);
  }
  return [...kept.values()];
}
```

```js
/** 청약홈 주택형 — LTTOT_TOP_AMOUNT 는 만원(11/23 청약홈 화면과 대조) → 원 */
export function fromApplyhomeModels(json) {
  if (!Array.isArray(json?.data)) throw new Error("applyhome mdl: data 없음");
  return [...json.data]
    .sort((a, b) => String(a.MODEL_NO).localeCompare(String(b.MODEL_NO)))
    .map((r) => {
      const m = /^(\d+(?:\.\d+)?)\s*([A-Z]*)/.exec(String(r.HOUSE_TY ?? "").trim());
      const price = won(r.LTTOT_TOP_AMOUNT);
      return {
        type: m ? `${Number(m[1])}㎡${m[2] ? ` ${m[2]}` : ""}` : String(r.HOUSE_TY ?? "").trim(),
        general: Number(r.SUPLY_HSHLDCO) || 0,
        special: Number(r.SPSPLY_HSHLDCO) || 0,
        topPrice: price === null ? null : price * 10_000,
      };
    });
}
```

```ts
import type { HousingNotice } from "./notices";

export interface NoticeComplex {
  name: string;
  address: string | null;
  /** 공급 N호, 0(잔여 매각) 이면 null */
  households: number | null;
  heating: string | null;
  /** 원. 마이홈 값은 모두 '가장 낮은 조건'(11/23 공고문 대조) */
  amounts: { label: string; won: number }[];
}

export interface NoticeHouseType {
  /** "59.85㎡ A" (전용면적) */
  type: string;
  general: number;
  special: number;
  /** 원(청약홈 만원 × 1만), 없으면 null */
  topPrice: number | null;
}

export interface NoticeDetail {
  /** end 가 null 이면 하루 */
  schedule: { label: string; start: string; end: string | null }[];
  facts: { label: string; value: string }[];
  complexes: NoticeComplex[];
  /** 청약홈 아파트만. 못 받았으면 null */
  houseTypes: NoticeHouseType[] | null;
  contact: { department: string; phone: string | null; url: string | null } | null;
}

export type DetailedNotice = HousingNotice & { detail?: NoticeDetail };

export const noticeHref = (id: string) => `/housing/notice?id=${encodeURIComponent(id)}`;
```
