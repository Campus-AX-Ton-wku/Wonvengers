# Perky QA 체크리스트

발표 전에 사람이 직접 클릭하며 확인한다. 자동 테스트가 잡지 못하는 것들이다.

## 정책 데이터

- [ ] `[예시]`로 시작하는 정책이 `data/policies.json`에 남아 있지 않다
- [ ] `verified_by`에 `예시데이터`라고 적힌 정책이 없다
- [ ] 모든 정책의 `apply_url`을 직접 열어 공식 페이지임을 확인했다
- [ ] 모든 정책을 작성자가 아닌 사람이 원문과 대조했다
- [ ] `benefit_summary` 문구가 공고 원문과 일치한다

## 1층 화면

- [ ] 질문 4개에 모두 `모름`을 골라도 목록이 뜬다
- [ ] 태그가 전부 `확인 필요`로만 나오지 않는다
- [ ] `해당 없음` 카드에 탈락 이유가 보인다
- [ ] 탈락 이유가 두 개인 경우 두 개가 모두 보인다
- [ ] 답변을 바꾸면 목록이 즉시 바뀐다
- [ ] 새로고침해도 답변이 남아 있다
- [ ] 신청 링크가 새 탭으로 열린다
- [ ] 맨 아래 고지 문구가 접히지 않고 항상 보인다

## 모바일

- [ ] 아이폰에서 홈 → /find → 공식 페이지 이동까지 끝까지 된다
- [ ] 안드로이드에서 같은 흐름이 된다
- [ ] 좌우로 화면이 밀리지 않는다
- [ ] 버튼이 손가락으로 누를 만한 크기다

## 배포

- [ ] 배포 URL에서 위 항목이 모두 동작한다
- [ ] 배포 URL을 팀원 전원이 열어봤다
