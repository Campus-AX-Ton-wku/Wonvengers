**`(자동)` 표시가 붙은 항목은 테스트로 고정했다** (`apps/web/app/__tests__/*.tsx`, 37건).
회귀는 `npm test` 가 잡으므로 손으로 다시 볼 필요는 없다. 나머지 — 실기기 터치, 화면이
한 눈에 들어오는지, 새로고침, 실제 링크가 열리는지 — 는 사람이 봐야 한다.

```bash
npm test        # 전체 187건 (jsdom 환경 준비에 3분쯤 걸린다)
npm run test:lib   # 판정·계산 로직만 140건 — 몇 초
npm run test:ui    # 화면 37건
```
