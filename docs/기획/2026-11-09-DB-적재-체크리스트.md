## 부록 A. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `npm test` 실행 시 "'node'은(는) 내부 또는 외부 명령... 아닙니다" | 이 PC에서 npm이 node 경로를 못 찾음 (11/9 확인) | `node db.test.mjs`처럼 node로 직접 실행 |
| API 응답이 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 승인 직후라 키가 아직 등록 안 됨, 또는 Encoding/Decoding 키를 바꿔 넣음 | 몇 시간 뒤 다시 시도, Decoding 키인지 확인 |
| `invalid input value for enum opt_...` | 선택지 타입에 없는 값 | 적용 전이면 마이그레이션의 `create type`에 추가 (3-1처럼). 적용 후면 `alter type public.opt_... add value '값';` |
| `violates check constraint "나이_범위"` 등 한글 규칙 이름 | 값이 규칙에 어긋남 (예: 나이 하한 > 상한) | 규칙 이름을 보고 값을 고침 |
| 수정이 거부되고 `edit_note` 이야기가 나옴 | 고친 이유를 안 적음 | `edit_note`에 원문 위치와 이유를 적음 |
| 검수 insert가 거부됨 | 본인이 고친 버전을 본인이 검수 | 다른 팀원이 검수 |
| Table Editor에서 고쳤더니 작성자가 이상함 | Studio에서 고치면 로그인 정보가 없음 (README 한계) | `edited_by`를 본인 id로 바꿔서 저장하거나 SQL로 고침 |
| seed 실행 시 `duplicate key` | seed를 두 번 실행 | 이미 들어가 있음. 다시 넣으려면 표를 비운 뒤 실행 |
| 빌드 후 dev 서버가 500 (`Cannot find module`) | `next build`가 dev 서버를 깨뜨림 | dev 서버를 껐다 다시 켬 (CLAUDE.md) |
