## 2. 규칙 — `lib/loans.ts` (순수 함수)

- 종류 이름 `LOAN_TYPE_LABEL`: `loan_interest_subsidy` "대출 · 이자 지원" · `guarantee_fee_subsidy` "보증료 지원" · `savings_account` "청약 · 저축" (결과 화면에 있던 이름 그대로 옮김)
- 지역 이름 `loanRegionLabel`: `regionScope` 의 마지막 낱말 — "전국" · "전북특별자치도 익산시" → "익산시"
- 한 줄 `loanMetaLine` = `종류 · 지역` (예: "대출 · 이자 지원 · 익산시")
- 고르기 · 순서 `orderedLoans(products, { region, housingType })` → `{ loans, tag }`
  - 지역 답이 있으면 `loanProductsForRegion` 으로 거른다(결과 화면과 같은 규칙). 없으면 전부
  - 집 형태별 앞 카드(있는 것만, 이 순서): 월세 · 연세 → `youth-btm-monthly-rent-loan` / 전세 → `youth-btm-jeonse-loan`, `iksan-youth-jeonse-loan-interest`. 나머지는 데이터 순서
  - 앞으로 옮긴 카드가 있으면 `tag` = "{집 형태}라면 먼저", 없으면 null
- `findLoan(products, id)`
