## 겹쳐서 깨졌을 때

1. **PR 에 "This branch has conflicts"** — 충돌 파일이 위 목록이면, develop 의 바뀐 내용을 앱 브랜치 위로 가져와 맞춘다.
   ```bash
   git switch feature/iksan-demo
   git fetch origin && git merge origin/develop   # 충돌 난 파일을 고친 뒤
   ```
   고친 뒤 아래 검사를 모두 통과시키고 push 한다.
2. **'PR 검사' 빨간불** — 어느 작업(앱 / Supabase)의 어느 단계가 실패했는지 보고, 같은 명령을 로컬에서 돌려 재현한다.
3. 로컬 검사 명령 (노찬영 PC 는 npm 스크립트가 node 를 못 찾아 바이너리를 직접 부른다):
   ```bash
   cd apps/web && npm ci --ignore-scripts
   node node_modules/typescript/bin/tsc --noEmit
   node node_modules/vitest/vitest.mjs run
   node node_modules/next/dist/bin/next build
   cd ../../supabase/tests && npm ci
   node redesign.test.mjs && node seed.test.mjs && node raw.test.mjs && node notice.test.mjs
   ```
