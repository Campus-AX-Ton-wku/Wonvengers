# 서류 떼는 곳 — 온라인 링크 · 지도 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 주거 가이드 '서류 떼는 곳 모음' 1장에 서류별 온라인 발급 링크를 달고, 익산 주민센터 · 무인민원발급기를 앱 안 카카오 지도(전체 화면 `/guides/places`)로 보여 준다.

**Architecture:** 위치 데이터는 빌드 때 받아 정적 파일(`data/civil-places.json`)로 커밋한다 — 무인민원발급기는 행정안전부 API, 주민센터는 카카오 로컬 키워드 검색, 발급기 좌표는 카카오 주소 검색. 화면은 그 파일만 읽고, 카카오 지도 JavaScript SDK 는 지도 화면에서만 불러온다. SDK 를 못 불러오면 같은 데이터를 목록으로 보여 준다.

**Tech Stack:** Next.js 15 App Router(정적 export) · TypeScript · Tailwind 4 · Vitest(jsdom) · 카카오맵 JavaScript SDK v2 · 카카오 로컬 REST API · data.go.kr 무인민원발급기정보 조회서비스.

**Spec:** `docs/기획/2026-11-22-서류-떼는-곳-지도-설계.md`

## Global Constraints

- F0-5 추정 금지 — 데이터에 없는 운영시간 · 서류 · 위치는 지어내지 않는다. 못 찾은 곳은 빼고 빌드 기록에 남긴다.
- 실행 중에는 카카오 검색 · 주소 변환을 부르지 않는다. `connect-src` 는 바꾸지 않는다.
- 키 이름: `NEXT_PUBLIC_KAKAO_JS_KEY`(지도, 공개) · `KAKAO_REST_KEY`(빌드만) · `BOJOGEUM_KEY`(공공데이터포털, 무인민원발급기 API 활용신청 승인됨 11/22).
- 키가 없거나 받기에 실패해도 빌드를 멈추지 않는다 — 커밋된 `civil-places.json` 을 그대로 쓴다. 받은 장소가 0곳이면 덮어쓰지 않는다.
- 화면은 공통 컴포넌트를 `@/app/components` 에서만 가져온다. 아이콘은 `@/app/components/icons`.
- `lib/types.ts` · `lib/date.ts` · `lib/user-data.ts` 는 건드리지 않는다(AWS 배포 경로).
- 문구는 해요체, 짧게. 외부 링크는 `target="_blank" rel="noopener noreferrer"` + ↗ 아이콘.
- 검증 명령(apps/web 에서): `node node_modules/typescript/bin/tsc --noEmit` · `node node_modules/vitest/vitest.mjs run` · `npm run build`.

**무인민원발급기 API** (`https://apis.data.go.kr/1741000/kiosk_info`, serviceKey · pageNo · numOfRows(최대 100) · returnType=json)

- 설치정보 `installation_info` — 시도 필터 `cond[CTPV_CD::EQ]=6540000`(전북, 익산 행이 이 값). 익산 = `OPN_ATMY_GRP_CD === "4681000"` → 26대, 모두 `USE_YN_NM: "사용"`. 좌표 없음.
  쓰는 칸: `MNG_NO` `ISSUMCHN_NM` `INSTL_PLC_ADDR` `INSTL_PLC_DTL_PSTN` `WKDY_OPER_BGNG_TM` `WKDY_OPER_END_TM` `LHLDY_OPER_BGNG_TM` `LHLDY_OPER_END_TM` `OPER_HR_REF_CN` `USE_YN_NM` `OPN_ATMY_GRP_CD`.
  값 예: 운영시간 `"00:00"`~`"2400"`(24시간), `"03:00"`~`"23:50"`, 공휴일 빈 문자열. 주소 예: `"전북특별자치도 익산시 고봉로 285, 국민건강보험공단 (영등동)"`, `"전북특별자치도 익산시 인북로 353(신동)[전북특별자치도 익산시 신동 806번지 1]"`.
- 발급제증명 `certificate_info` — `cond[SGG_NM::LIKE]=익산` → 2,506행(발급기 28대 × 서류). 한 행 = 발급기 하나의 서류 하나. 조인: `ISSUMCHN_NO`(발급제증명) = `MNG_NO`(설치정보).
  우리 서류 이름(`CVLCPT_OFCWORK_CLSF_NM`)과 익산 발급기 수: `주민등록표(등본)` 27 · `가족관계증명서` 24 · `건강보험 자격득실확인서` 27 · `소득금액증명` 27 · `건축물대장` 27 · `부동산등기사항증명서` 10.

```ts
/**
 * 서류 떼는 곳 지도의 장소 (docs/기획/2026-11-22-서류-떼는-곳-지도-설계.md).
 *
 * 데이터는 빌드 때 scripts/fetch-civil-places.mjs 가 data/civil-places.json 으로 만든다 — 화면은 그 파일만 읽는다.
 * 무인민원발급기: 행정안전부 무인민원발급기정보 조회서비스 · 주민센터: 카카오 장소 검색. 없는 값은 null 로 둔다(F0-5).
 */

export type PlaceKind = "office" | "kiosk";

/** 무인민원발급기 API 의 서류 이름(CVLCPT_OFCWORK_CLSF_NM) → 화면 이름. 가이드 1장의 서류와 같은 이름을 쓴다 */
export const KIOSK_DOCS = [
  { key: "resident", api: "주민등록표(등본)", label: "주민등록등본" },
  { key: "family", api: "가족관계증명서", label: "가족관계증명서" },
  { key: "health", api: "건강보험 자격득실확인서", label: "건강보험 자격득실확인서" },
  { key: "income", api: "소득금액증명", label: "소득금액증명" },
  { key: "building", api: "건축물대장", label: "건축물대장" },
  { key: "registry", api: "부동산등기사항증명서", label: "등기부등본" },
] as const;

export type KioskDocKey = (typeof KIOSK_DOCS)[number]["key"];

export interface CivilPlace {
  id: string;
  kind: PlaceKind;
  name: string;
  address: string;
  /** 설치 장소 상세 (발급기) */
  detail: string | null;
  phone: string | null;
  lat: number;
  lng: number;
  /** 평일 운영시간 (발급기). 데이터에 없으면 null */
  weekday: string | null;
  /** 공휴일 운영시간 (발급기). 데이터에 없으면 null — '운영 안 함'으로 읽지 않는다 */
  holiday: string | null;
  /** 운영시간 참고 (발급기) */
  hoursNote: string | null;
  /** 뗄 수 있는 서류 (발급기만, 우리 서류 6개 중) */
  documents: KioskDocKey[];
}

export interface CivilPlacesSnapshot {
  generatedAt: string | null;
  places: CivilPlace[];
}

/** API 운영시간 두 칸 → 한 줄. '2400' 은 24:00, 00:00~24:00 은 24시간. 한쪽이라도 비면 null */
export function formatHours(begin: string, end: string): string | null {
  const b = begin.trim();
  const e = end.trim() === "2400" ? "24:00" : end.trim();
  if (!b || !e) return null;
  if (b === "00:00" && e === "24:00") return "24시간";
  return `${b}~${e}`;
}

export function filterPlaces(
  places: CivilPlace[],
  { kind, doc }: { kind: "all" | PlaceKind; doc: KioskDocKey | null }
): CivilPlace[] {
  return places.filter((p) => {
    if (kind !== "all" && p.kind !== kind) return false;
    if (doc && !p.documents.includes(doc)) return false;
    return true;
  });
}

/** 두 지점 사이 직선거리(km), 하버사인 */
export function distanceKm(a: { lat: number; lng: number }, b: { lat: number; lng: number }): number {
  const R = 6371;
  const rad = (d: number) => (d * Math.PI) / 180;
  const dLat = rad(b.lat - a.lat);
  const dLng = rad(b.lng - a.lng);
  const h = Math.sin(dLat / 2) ** 2 + Math.cos(rad(a.lat)) * Math.cos(rad(b.lat)) * Math.sin(dLng / 2) ** 2;
  return 2 * R * Math.asin(Math.sqrt(h));
}

export function formatDistance(km: number): string {
  return km < 1 ? `${Math.round(km * 1000)}m` : `${km.toFixed(1)}km`;
}

/** 카카오맵 길찾기(목적지만 정해 둔 링크). 출발지는 카카오맵이 묻는다 */
export function directionsUrl(p: CivilPlace): string {
  return `https://map.kakao.com/link/to/${encodeURIComponent(p.name)},${p.lat},${p.lng}`;
}
```

```js
/** 주소 → 카카오 주소 검색어. 지번 [..] · 쉼표 뒤 건물명 · 끝 (동) 을 뗀다 */
export function geocodeQuery(addr) {
  return addr.split("[")[0].split(",")[0].replace(/\([^)]*\)\s*$/, "").trim();
}

function hours(begin, end) {
  const b = (begin ?? "").trim();
  const e = (end ?? "").trim() === "2400" ? "24:00" : (end ?? "").trim();
  if (!b || !e) return null;
  if (b === "00:00" && e === "24:00") return "24시간";
  return `${b}~${e}`;
}

/**
 * 설치정보 + 발급제증명 → 발급기 장소. 익산 · 사용 중 · 좌표가 있는 것만.
 * coords: MNG_NO → 좌표 (fetch 스크립트가 카카오 주소 검색으로 채운다)
 */
export function toKiosks(installRows, certRows, coords) {
  const docsByNo = new Map();
  for (const c of certRows) {
    const doc = KIOSK_DOCS.find((d) => d.api === c.CVLCPT_OFCWORK_CLSF_NM);
    if (!doc) continue;
    if (!docsByNo.has(c.ISSUMCHN_NO)) docsByNo.set(c.ISSUMCHN_NO, new Set());
    docsByNo.get(c.ISSUMCHN_NO).add(doc.key);
  }
  const places = [];
  const skipped = [];
  for (const r of installRows) {
    if (r.OPN_ATMY_GRP_CD !== IKSAN_GROUP_CD || r.USE_YN_NM !== "사용") continue;
    const at = coords.get(r.MNG_NO);
    if (!at) {
      skipped.push(`${r.MNG_NO} ${r.ISSUMCHN_NM} — 좌표를 못 찾음`);
      continue;
    }
    const have = docsByNo.get(r.MNG_NO) ?? new Set();
    places.push({
      id: `kiosk-${r.MNG_NO}`,
      kind: "kiosk",
      name: r.ISSUMCHN_NM,
      address: geocodeQuery(r.INSTL_PLC_ADDR),
      detail: r.INSTL_PLC_DTL_PSTN?.trim() || null,
      phone: null,
      lat: at.lat,
      lng: at.lng,
      weekday: hours(r.WKDY_OPER_BGNG_TM, r.WKDY_OPER_END_TM),
      holiday: hours(r.LHLDY_OPER_BGNG_TM, r.LHLDY_OPER_END_TM),
      hoursNote: r.OPER_HR_REF_CN?.trim() || null,
      documents: KIOSK_DOCS.filter((d) => have.has(d.key)).map((d) => d.key),
    });
  }
  return { places, skipped };
}

export function formatSnapshot(snapshot) {
  return `${JSON.stringify(snapshot, null, 2)}\n`;
}
```

```js
//   node scripts/fetch-civil-places.mjs   # 키가 있으면 받아서 쓰고, 없거나 실패하면 커밋된 파일 그대로

import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

function readKey(name) {
  if (process.env[name]?.trim()) return process.env[name].trim();
  for (const file of [".env.local", ".env"]) {
    try {
      const hit = readFileSync(join(WEB_ROOT, file), "utf8").match(new RegExp(`^\\s*${name}\\s*=\\s*(.+)$`, "m"));
      if (hit) return hit[1].trim().replace(/^["']|["']$/g, "");
    } catch {
      // 파일이 없으면 다음 후보로
    }
  }
  return null;
}

const DATA_KEY = readKey("BOJOGEUM_KEY");
const KAKAO_KEY = readKey("KAKAO_REST_KEY");

async function getJson(url, headers = {}, attempt = 1) {
  try {
    const res = await fetch(url, { headers, signal: AbortSignal.timeout(15_000) });
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (err) {
    if (attempt >= 3) throw err;
    await new Promise((r) => setTimeout(r, 1_500 * attempt));
    return getJson(url, headers, attempt + 1);
  }
}

/** 무인민원발급기 API 한 오퍼레이션을 끝까지 넘겨 받는다 */
async function allRows(op, cond) {
  const rows = [];
  for (let page = 1; page < 200; page++) {
    const url = new URL(`https://apis.data.go.kr/1741000/kiosk_info/${op}`);
    url.searchParams.set("serviceKey", DATA_KEY);
    url.searchParams.set("pageNo", String(page));
    url.searchParams.set("numOfRows", "100");
    url.searchParams.set("returnType", "json");
    for (const [k, v] of Object.entries(cond)) url.searchParams.set(k, v);
    const body = (await getJson(url)).response?.body;
    const items = [].concat(body?.items?.item ?? []);
    rows.push(...items);
    if (items.length < 100 || rows.length >= Number(body?.totalCount ?? 0)) break;
  }
  return rows;
}

const kakao = (path, query) =>
  getJson(`https://dapi.kakao.com/v2/local/search/${path}.json?${new URLSearchParams(query)}`, {
    Authorization: `KakaoAK ${KAKAO_KEY}`,
  });

async function main() {
  if (!DATA_KEY || !KAKAO_KEY) {
    log("BOJOGEUM_KEY · KAKAO_REST_KEY 중 없는 키가 있다 — 커밋된 data/civil-places.json 을 그대로 쓴다");
    return;
  }

  const offices = [];
  for (const emd of IKSAN_EMD) {
    const { documents = [] } = await kakao("keyword", { query: `익산 ${emd} 행정복지센터`, size: "5" });
    const hit = pickOffice(emd, documents);
    if (hit) offices.push(toOffice(emd, hit));
    else log(`주민센터를 못 찾음: ${emd}`);
  }

  const install = await allRows("installation_info", { "cond[CTPV_CD::EQ]": JEONBUK_CTPV_CD });
  const certs = await allRows("certificate_info", { "cond[SGG_NM::LIKE]": "익산" });
  const coords = new Map();
  for (const r of install) {
    if (r.OPN_ATMY_GRP_CD !== "4681000" || r.USE_YN_NM !== "사용") continue;
    const { documents = [] } = await kakao("address", { query: geocodeQuery(r.INSTL_PLC_ADDR) });
    if (documents[0]) coords.set(r.MNG_NO, { lat: Number(documents[0].y), lng: Number(documents[0].x) });
  }
  const { places: kiosks, skipped } = toKiosks(install, certs, coords);
  for (const s of skipped) log(`발급기 뺌: ${s}`);

  const places = [...offices, ...kiosks];
  if (places.length === 0) {
    log("받은 장소가 0곳 — 덮어쓰지 않는다");
    return;
  }
  const generatedAt = new Date(Date.now() + 9 * 3600_000).toISOString().slice(0, 10);
  writeFileSync(OUT, formatSnapshot({ generatedAt, places }));
  log(`주민센터 ${offices.length}곳 · 발급기 ${kiosks.length}대 → data/civil-places.json`);
}

main().catch((err) => log(`실패 — 커밋된 파일을 그대로 쓴다: ${err.message}`));
```

```ts
/**
 * 카카오 지도 JavaScript SDK 를 한 번만 불러온다 (서류 떼는 곳 지도, 11/22).
 * 키는 NEXT_PUBLIC_KAKAO_JS_KEY — 카카오 콘솔에서 도메인(wonvengers.vercel.app · localhost:3000 · 127.0.0.1:4321)으로 묶여 있다.
 * 키가 없거나 · 스크립트가 막히거나 · 시간이 지나면 실패로 끝낸다 — 화면은 목록으로 보여 준다.
 */

// SDK 는 타입을 주지 않는다. 쓰는 곳(PlacesView)에서만 좁게 다룬다.
// eslint-disable-next-line @typescript-eslint/no-explicit-any
export type KakaoMaps = any;

let pending: Promise<KakaoMaps> | null = null;

export function loadKakaoMaps(appKey: string | undefined, timeoutMs = 8_000): Promise<KakaoMaps> {
  if (!appKey) return Promise.reject(new Error("no-key"));
  const w = window as { kakao?: { maps?: KakaoMaps } };
  if (w.kakao?.maps?.LatLng) return Promise.resolve(w.kakao.maps);
  if (pending) return pending;
  pending = new Promise<KakaoMaps>((resolve, reject) => {
    const script = document.createElement("script");
    script.src = `https://dapi.kakao.com/v2/maps/sdk.js?appkey=${encodeURIComponent(appKey)}&autoload=false`;
    script.async = true;
    const timer = setTimeout(() => reject(new Error("timeout")), timeoutMs);
    script.addEventListener("load", () => {
      const maps = w.kakao?.maps;
      if (!maps) {
        clearTimeout(timer);
        reject(new Error("no-sdk"));
        return;
      }
      maps.load(() => {
        clearTimeout(timer);
        resolve(maps);
      });
    });
    script.addEventListener("error", () => {
      clearTimeout(timer);
      reject(new Error("load-failed"));
    });
    document.head.appendChild(script);
  }).catch((err) => {
    pending = null;
    throw err;
  });
  return pending;
}

export function resetKakaoMapsForTest(): void {
  pending = null;
}
```

```tsx
"use client";

import Link from "next/link";
import { useEffect, useMemo, useRef, useState } from "react";
import { AppShell, buttonClass, telHref, TopBar } from "@/app/components";
import { ArrowUpRight, Compass, ICON_SM, MapPin, Phone } from "@/app/components/icons";
import { loadKakaoMaps, type KakaoMaps } from "@/lib/kakao-map";
import {
  directionsUrl,
  distanceKm,
  filterPlaces,
  formatDistance,
  KIOSK_DOCS,
  type CivilPlace,
  type KioskDocKey,
  type PlaceKind,
} from "@/lib/places";

const KIND_LABEL: Record<PlaceKind, string> = { office: "주민센터", kiosk: "무인민원발급기" };
const docLabel = (key: KioskDocKey) => KIOSK_DOCS.find((d) => d.key === key)!.label;

type MapState = "loading" | "ready" | "failed";

/**
 * 서류 떼는 곳 지도 (11/22 ggue). 지도는 카카오 SDK, 같은 데이터를 목록으로도 — 화면 읽기 프로그램은 지도를 못 쓴다.
 * 위치 권한은 [내 위치]를 누를 때만 묻고, 받은 위치는 이 화면에서 지도 가운데와 거리 계산에만 쓴다(저장 · 전송 안 함).
 */
export function PlacesView({
  places,
  generatedAt,
  jsKey,
}: {
  places: CivilPlace[];
  generatedAt: string | null;
  jsKey: string | undefined;
}) {
  const [kind, setKind] = useState<"all" | PlaceKind>("all");
  const [doc, setDoc] = useState<KioskDocKey | null>(null);
  const [selectedId, setSelectedId] = useState<string | null>(null);
  const [me, setMe] = useState<{ lat: number; lng: number } | null>(null);
  const [notice, setNotice] = useState<string | null>(null);
  const [mapState, setMapState] = useState<MapState>("loading");
  const mapEl = useRef<HTMLDivElement>(null);
  const mapRef = useRef<{ maps: KakaoMaps; map: KakaoMaps; overlays: KakaoMaps[] } | null>(null);

  const shown = useMemo(() => {
    const list = filterPlaces(places, { kind, doc });
    return me ? [...list].sort((a, b) => distanceKm(me, a) - distanceKm(me, b)) : list;
  }, [places, kind, doc, me]);
  const selected = shown.find((p) => p.id === selectedId) ?? null;

  // 지도 SDK — 장소가 있을 때만
  useEffect(() => {
    if (places.length === 0) return;
    let alive = true;
    loadKakaoMaps(jsKey)
      .then((maps) => {
        if (!alive || !mapEl.current) return;
        const map = new maps.Map(mapEl.current, { center: new maps.LatLng(35.9483, 126.9577), level: 7 });
        mapRef.current = { maps, map, overlays: [] };
        setMapState("ready");
      })
      .catch(() => alive && setMapState("failed"));
    return () => {
      alive = false;
    };
  }, [jsKey, places.length]);

  // 거른 장소를 지도에 — 바뀔 때마다 다시 그린다
  useEffect(() => {
    const m = mapRef.current;
    if (mapState !== "ready" || !m) return;
    for (const o of m.overlays) o.setMap(null);
    const bounds = new m.maps.LatLngBounds();
    m.overlays = shown.map((p) => {
      const pos = new m.maps.LatLng(p.lat, p.lng);
      bounds.extend(pos);
      const el = document.createElement("button");
      el.type = "button";
      el.setAttribute("aria-label", p.name);
      el.className =
        p.kind === "office"
          ? "size-5 rounded-full border-2 border-white bg-brand-700 shadow-card"
          : "size-5 rounded-full border-2 border-white bg-warn-800 shadow-card";
      el.addEventListener("click", () => setSelectedId(p.id));
      return new m.maps.CustomOverlay({ position: pos, content: el, yAnchor: 0.5, map: m.map });
    });
    if (me) {
      const dot = document.createElement("span");
      dot.className = "block size-4 rounded-full border-2 border-white bg-ok-600 shadow-card";
      m.overlays.push(new m.maps.CustomOverlay({ position: new m.maps.LatLng(me.lat, me.lng), content: dot, yAnchor: 0.5, map: m.map }));
      m.map.setCenter(new m.maps.LatLng(me.lat, me.lng));
      m.map.setLevel(5);
    } else if (shown.length > 0) {
      m.map.setBounds(bounds);
    }
  }, [mapState, shown, me]);

  function locate() {
    const geo = typeof navigator !== "undefined" ? navigator.geolocation : undefined;
    if (!geo) {
      setNotice("위치 권한이 없어 익산 전체를 보여 드려요");
      return;
    }
    geo.getCurrentPosition(
      (pos) => {
        setNotice(null);
        setMe({ lat: pos.coords.latitude, lng: pos.coords.longitude });
      },
      () => setNotice("위치 권한이 없어 익산 전체를 보여 드려요"),
      { timeout: 8_000, maximumAge: 60_000 }
    );
  }

  const chip = (active: boolean) =>
    `focus-ring h-9 shrink-0 rounded-full px-3.5 text-sm font-bold ${active ? "bg-brand-600 text-white" : "bg-surface text-ink-700 shadow-card"}`;

  if (places.length === 0) {
    return (
      <AppShell>
        <TopBar backHref="/guides/where-documents/1" />
        <main className="flex flex-1 flex-col gap-4 pt-2.5">
          <h1 className="text-[26px] font-extrabold text-ink-900">서류 떼는 곳 지도</h1>
          <p className="text-[15px] text-ink-700">아직 보여 줄 곳이 없어요</p>
          <Link href="/guides/where-documents/1" className={buttonClass({ variant: "secondary", size: "md" })}>
            온라인으로 떼는 곳 보기
          </Link>
        </main>
      </AppShell>
    );
  }

  return (
    <AppShell>
      <TopBar backHref="/guides/where-documents/1" />
      <main className="flex flex-1 flex-col gap-3 pb-10 pt-2.5">
        <h1 className="text-[26px] font-extrabold text-ink-900">서류 떼는 곳 지도</h1>

        <div className="-mx-4 flex gap-2 overflow-x-auto px-4 pb-1">
          {(["all", "office", "kiosk"] as const).map((k) => (
            <button
              key={k}
              type="button"
              aria-pressed={kind === k}
              className={chip(kind === k)}
              onClick={() => {
                setKind(k);
                if (k !== "kiosk") setDoc(null);
              }}
            >
              {k === "all" ? "전체" : KIND_LABEL[k]}
            </button>
          ))}
        </div>
        {kind === "kiosk" && (
          <div className="-mx-4 flex gap-2 overflow-x-auto px-4 pb-1">
            {KIOSK_DOCS.map((d) => (
              <button key={d.key} type="button" aria-pressed={doc === d.key} className={chip(doc === d.key)} onClick={() => setDoc(doc === d.key ? null : d.key)}>
                {d.label}
              </button>
            ))}
          </div>
        )}

        <div className="flex items-center justify-between gap-2">
          <p className="flex items-center gap-3 text-xs text-ink-600">
            <span className="flex items-center gap-1"><span aria-hidden="true" className="size-3 rounded-full bg-brand-700" />주민센터</span>
            <span className="flex items-center gap-1"><span aria-hidden="true" className="size-3 rounded-full bg-warn-800" />무인민원발급기</span>
          </p>
          <button type="button" onClick={locate} className={buttonClass({ variant: "quiet", size: "md" })}>
            <Compass size={ICON_SM} aria-hidden="true" />
            내 위치
          </button>
        </div>
        {notice && <p className="text-sm text-ink-600">{notice}</p>}

        {mapState === "failed" ? (
          <p className="rounded-card bg-ink-50 p-4 text-sm text-ink-700">지도를 불러오지 못했어요 — 목록으로 보여 드려요</p>
        ) : (
          <div ref={mapEl} aria-hidden="true" className="h-[52vh] min-h-[280px] overflow-hidden rounded-card bg-ink-100" />
        )}

        {selected && (
          <section aria-labelledby="place-card" className="flex flex-col gap-1.5 rounded-card bg-surface p-4 shadow-card">
            <p className="text-xs font-bold text-brand-700">{KIND_LABEL[selected.kind]}</p>
            <h2 id="place-card" className="text-lg font-extrabold text-ink-900">{selected.name}</h2>
            <p className="text-sm text-ink-700">{selected.address}</p>
            {selected.detail && <p className="text-sm text-ink-600">{selected.detail}</p>}
            {selected.weekday && <p className="text-sm text-ink-700">평일 {selected.weekday}</p>}
            {selected.holiday && <p className="text-sm text-ink-700">공휴일 {selected.holiday}</p>}
            {selected.hoursNote && <p className="text-xs text-ink-500">{selected.hoursNote}</p>}
            {selected.documents.length > 0 && (
              <p className="text-sm text-ink-700">{selected.documents.map(docLabel).join(" · ")}</p>
            )}
            <div className="mt-2 flex gap-2">
              <a
                href={directionsUrl(selected)}
                target="_blank"
                rel="noopener noreferrer"
                className={buttonClass({ variant: "primary", size: "md" })}
              >
                길찾기
                <ArrowUpRight size={ICON_SM} aria-hidden="true" />
              </a>
              {selected.phone && (
                <a href={telHref(selected.phone)} className={buttonClass({ variant: "secondary", size: "md" })}>
                  <Phone size={ICON_SM} aria-hidden="true" />
                  전화
                </a>
              )}
            </div>
          </section>
        )}

        <ul aria-label="장소 목록" className="flex flex-col gap-2">
          {shown.map((p) => (
            <li key={p.id}>
              <button
                type="button"
                onClick={() => setSelectedId(p.id)}
                aria-pressed={selectedId === p.id}
                className="focus-ring flex w-full items-start gap-2.5 rounded-card bg-surface p-3.5 text-left shadow-card"
              >
                <MapPin size={ICON_SM} aria-hidden="true" className={`mt-1 shrink-0 ${p.kind === "office" ? "text-brand-700" : "text-warn-800"}`} />
                <span className="flex min-w-0 flex-col">
                  <span className="text-[15px] font-bold text-ink-900">{p.name}</span>
                  <span className="text-xs text-ink-600">
                    {KIND_LABEL[p.kind]}
                    {me && ` · ${formatDistance(distanceKm(me, p))}`}
                  </span>
                </span>
              </button>
            </li>
          ))}
        </ul>

        <p className="text-xs text-ink-500">
          출처: 행정안전부 무인민원발급기정보 · 카카오 장소 검색{generatedAt ? ` · ${generatedAt} 기준` : ""}
        </p>
      </main>
    </AppShell>
  );
}
```
