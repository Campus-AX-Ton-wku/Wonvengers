# 내 프로필 · 배지 — 설계 (2026-11-22, ggue 승인)

시안: Claude Design artifact `3zZArhhTanweCC8sseai8m` 보드 Profile · ProfileSpec(v `1795347322-62ab`), 홈 인사는 Main · HomePlus.
**두 번에 나눠 올린다** (ggue 선택): ① 프로필(이 문서 1~6절) → ② 배지(7절, 따로 설계를 보여 주고 올림).
서버 저장 형식은 ①에서 프로필 · 배지 칸을 한 번에 연다 — AWS 배포 승인은 한 번.

## 1. 저장 — 계정에 (동기화)

| 칸 | 모양 | 이 기기 키 |
|---|---|---|
| `profileCard` | `{ icon, color, name: string \| null, pinnedBadge: BadgeId \| null }` 또는 `null`(안 꾸밈) | `perky.profile-card` |
| `badges` | `{ [BadgeId]: "YYYY-MM-DD" }` 받은 날 — ①에서는 늘 `{}` | `perky.badges` |

- 이름이 `profileCard` 인 까닭: 동기화 데이터에 자격 답이 이미 `profile` 이다.
- 서버 검사(`lib/user-data.ts`)는 두 칸을 **없어도 받는 칸**(`OPTIONAL_PAYLOAD_KEYS`)으로 — 홈 화면에 캐시된 예전 앱도 계속 저장된다.
  웹은 비어 있으면 빼고 보낸다(`payloadFor`, 11/17 찜과 같은 방식) — AWS 배포 승인 전에는 프로필을 꾸민 사람만 저장이 잠깐 실패한다.
- API `store.ts` `DATA_KEYS` 에 두 칸 추가(읽을 때 고르는 목록).
- 회원 탈퇴는 서버 항목을 통째로 지운다 → 함께 지워진다. 로그아웃은 이 기기 사본에서도 지운다(`clearLocalContent`).
- **'처음부터 다시'(답 비우기)는 프로필 · 배지를 남긴다** — 답이 아니다. `resetAllAnswers` 가 지우기 전에 읽어 두었다가 다시 쓴다.
- 처리방침 · 동의 화면 수집 항목에 **'프로필(그림 · 색 · 이름 · 대표 배지) · 배지 기록'** 한 줄.
  **동의 버전(`CONSENT_VERSION`)은 올리지 않는다** — 11/17 관심 지원금 줄과 같게. 올리면 기존 사용자 모두 동의를 다시 해야 한다.

검사 규칙: `icon` · `color` 는 정해진 6개 중 하나, `name` 은 null 또는 앞뒤 빈칸 없는 1~10자(글자 단위, 제어 문자 금지),
`pinnedBadge` 는 null 또는 배지 id, `badges` 키는 배지 id 8개 중, 값은 날짜.

## 2. 그림 · 색 · 이름

- 그림 6(기존 3D 아이콘, 새로 그리지 않음): 집 `rent` · 열쇠 `move-in` · 이삿짐 `moving` · 학사모 `student` · 지갑 `wallet` · 지킴이 집 `guarantee`
- 색 6(시안 값): 파랑 `#d6e6ff`/물들임 `#eaf2ff` · 민트 `#cdf0df`/`#e9f8f1` · 복숭아 `#ffdccb`/`#fff1ea` · 레몬 `#ffeeb0`/`#fff8dc` · 라벤더 `#e3daff`/`#f3effe` · 하늘 `#cdeefa`/`#eaf7fd`
  (레몬 · 하늘 물들임은 시안에 없어 같은 계열로 만듦). 어두운 화면에서는 같은 색을 반투명으로 겹친다. 글자색은 바꾸지 않는다.
- 기본값: 집 · 파랑 · 기본 이름.
- **기본 이름** = 사는 곳 + " 사는 " + 상태 — "익산 사는 대학생". 사는 곳은 마지막 행정구역에서 시 · 군 · 구를 뗀 이름(전북특별자치도 익산시 → 익산),
  시 · 도만 고른 경우 그 이름. 상태: 대학생 → 대학생, **재직 → 직장인, 구직 → 구직자**. 하나만 있으면 있는 것만("익산 사는 청년" · "대학생"), 둘 다 없으면 "청년".
- 직접 정한 이름은 최대 10자, 앞뒤 빈칸을 지우고 비면 기본 이름.

## 3. 내 정보 (`/account`, 로그인했을 때)

위에서 아래로:
1. 상단바 — 왼쪽 제목 '내 정보'(h1) + 알림 종. 탭 화면이라 뒤로 가기 없음.
2. **프로필 카드** — 위쪽이 고른 색으로 물든 카드. 96px 그림 동그라미, 이름, 기본 이름이면 "내 조건으로 지은 이름이에요 · 바꿀 수 있어요",
   조건 칩(나이 · 지역 · 상태 · 집 형태), [프로필 꾸미기] [내 조건 수정](→ /find).
3. **내 기록** — 관심 지원금 n개(→ /saved) · 신청 준비 중 n개(→ /saved) · 달력 기록 n달(→ /ledger). 금액은 안 보인다.
   신청 준비 중 = 관심 지원금 중 체크를 하나라도 했지만 다 마치지 않은 것.
4. 설정 — 알림 설정 ›(알림을 쓸 수 있을 때) · 화면 모드(지금 그대로) · 개인정보 처리방침 ›
5. 계정 — "카카오로 로그인했어요 · 마지막 저장 11.22 17:10", 저장 오류 줄(지금 그대로), [로그아웃], 회원 탈퇴(밑줄 글자). 탈퇴 · 로그아웃 확인 창 그대로.

로그인 전 · 로그인 못 씀 · 탈퇴 끝 상태는 지금 그대로.
