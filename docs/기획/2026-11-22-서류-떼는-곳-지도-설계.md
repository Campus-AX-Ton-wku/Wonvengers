# 서류 떼는 곳 — 온라인 링크 · 지도 설계 (2026-11-22, ggue 승인)

## 왜

주거 가이드 '서류 떼는 곳 모음'(`lib/guides.ts` `where-documents`) 1장은 서류 7개와 떼는 곳을 **글로만** 적는다.
읽은 사람이 바로 움직일 수 있게 한다.

- 온라인으로 떼려는 사람 → 그 서류 발급 화면으로 바로 가는 링크
- 주민센터 · 무인민원발급기에서 떼려는 사람 → 지도에서 위치를 보고 길찾기

## 결정 (11/21~22 ggue)

| 질문 | 결정 |
|---|---|
| 오프라인 위치를 어떻게 보여 주나 | **앱 안에 지도** (카카오맵 JavaScript SDK) |
| 무인민원발급기 위치 출처 | **공공데이터** — 행정안전부_무인민원발급기정보 조회서비스 (data.go.kr 15154774) |
| 주민센터 위치 출처 | **카카오 장소 검색 결과를 빌드 때 받아 넣기** (익산 주민센터는 공공데이터에 없다) |
| 지도 자리 | **전체 화면 따로** — 가이드 1장의 버튼으로 연다 |

시연은 영상으로만 하므로(현장 HTML 안 만듦) 외부 지도 API 가 대회 규칙에 걸리지 않는다.

## 1. 화면

### 가이드 1장 "어디서 떼요? 한눈에 보기"

- 서류마다 **[온라인으로 떼기 ↗]** 링크. 그 기관의 해당 서류 발급 화면으로 바로 간다.
- 바로 가는 주소는 구현 때 하나씩 열어(HTTP 200 · 제목) 확인한다. 확인 못 한 서류는 그 기관 첫 화면으로 건다.
- 목록 아래 **[가까운 주민센터 · 무인민원발급기 지도 보기]** 버튼 → `/guides/places`.
- 다른 가이드의 `where`(글 목록)는 그대로 둔다. 이 장만 서류 단위 칸(`documents`)을 새로 쓴다.

### 지도 화면 `/guides/places`

- ← 는 가이드 1장(`/guides/where-documents/1`).
- 위쪽 거르기 칩: **전체 · 주민센터 · 무인민원발급기**. 발급기 데이터에 서류별 발급 여부가 있으면 서류 칩(예: '가족관계증명서 되는 곳')을 더한다 — 데이터에 없는 서류는 칩을 만들지 않는다.
- 처음에는 익산의 모든 표시가 들어오게 맞춘다. 주민센터와 발급기는 다른 표시 + 범례.
- **[내 위치]** 를 누를 때만 위치 권한을 묻는다. 거절 · 실패하면 "위치 권한이 없어 익산 전체를 보여 드려요".
- 표시를 누르면 아래 카드: 이름 · 종류 · 주소(+상세 위치) · 운영시간(발급기는 평일 · 공휴일) · 전화(주민센터) · 뗄 수 있는 서류(데이터에 있으면) · **[길찾기 ↗]**(카카오맵 길찾기 링크 `https://map.kakao.com/link/to/{이름},{위도},{경도}`) · **[전화]**(`tel:`).
- **[목록으로 보기]** — 같은 정보를 목록으로. 화면 읽기 프로그램은 지도를 쓸 수 없다. 내 위치를 허용했으면 가까운 순.

## 2. 데이터 — 빌드 때 받아 정적 파일로

정책 데이터(`scripts/fetch-app-data.mjs`)와 같은 방식. 앱은 실행 중에 위치 데이터를 부르지 않는다.

- 새 스크립트 `apps/web/scripts/fetch-civil-places.mjs` → `apps/web/data/civil-places.json` (커밋하는 스냅숏).
- `prebuild` 에서 정책 데이터 다음에 돈다.

### 주민센터

- 익산 읍면동 29곳 — 함열읍 · 함라면 · 웅포면 · 성당면 · 용안면 · 낭산면 · 망성면 · 여산면 · 금마면 · 왕궁면 · 춘포면 · 삼기면 · 용동면 · 오산면 · 황등면 · 인화동 · 동산동 · 마동 · 남중동 · 모현동 · 송학동 · 중앙동 · 평화동 · 신동 · 영등1동 · 영등2동 · 어양동 · 팔봉동 · 삼성동. 구현 때 행정표준코드(행정구역) 목록과 대조해 고정한다.
- 각 읍면동마다 카카오 로컬 키워드 검색 `익산 {읍면동} 행정복지센터` (REST `https://dapi.kakao.com/v2/local/search/keyword.json`, 헤더 `Authorization: KakaoAK {KAKAO_REST_KEY}`).
- 쓰는 결과: 장소 이름에 그 읍면동 이름이 있고 주소가 '익산'인 첫 결과. 못 찾으면 빌드 기록에 남기고 뺀다(지어내지 않는다).
- 남기는 칸: 이름 · 주소 · 전화 · 위도 · 경도 · 카카오 장소 주소.

### 무인민원발급기

- 행정안전부 API `https://apis.data.go.kr/1741000/kiosk_info/…` (serviceKey 필요, 시군구 이름 `익산` 으로 거른다).
- 응답 칸 목록은 명세 페이지에 없다 — **활용신청 승인 뒤 실제 응답을 보고 칸을 고정**한다. 다른 지자체 파일 데이터의 칸(관리기관명 · 발급기명 · 도로명주소 · 설치장소상세위치 · 평일/공휴일 운영 시작 · 종료 · 운영시간참고 · 사용여부 · 서류별 발급여부)이 같은 표준에서 온 것으로 보인다.
- 사용 중이 아닌 발급기는 뺀다. 좌표가 없으면 카카오 주소 검색(`/v2/local/search/address.json`)으로 바꾸고, 못 바꾸면 뺀다.

### 받기 실패

- 키가 없거나 받기에 실패하면 커밋된 마지막 `civil-places.json` 을 그대로 쓴다(빌드를 멈추지 않는다). PR 검사 · 로컬 빌드는 이 파일로 돈다.
- 받은 수가 0 이면 덮어쓰지 않는다.

## 3. 보안 설정 · 키 · 콘솔

- **CSP**(`lib/csp.ts`): `script-src` 에 카카오 지도 스크립트 출처(`https://dapi.kakao.com`, `https://t1.daumcdn.net`), `img-src` 에 지도 타일 · 표시 이미지 출처를 더한다. **`connect-src` 는 그대로** — 실행 중에 카카오 검색을 부르지 않으므로 토큰을 밖으로 보낼 길이 늘지 않는다. 정확한 출처 목록은 실제로 띄워 막히는 것만 연다.
- 키: `NEXT_PUBLIC_KAKAO_JS_KEY`(공개, 카카오 콘솔에서 도메인 제한) · `KAKAO_REST_KEY`(빌드만) · 무인민원발급기는 기존 공공데이터 키(`BOJOGEUM_KEY`)를 같은 계정 활용신청으로 쓴다.
- ggue 가 할 일: 카카오 개발자 콘솔(로그인용 앱)에서 카카오맵 사용 설정 · JavaScript SDK 도메인(정식 주소 · 로컬 확인 주소) 등록, Vercel 에 두 키, 공공데이터포털 무인민원발급기 API 활용신청.

## 4. 실패할 때

- 지도 SDK 를 못 불러오면(오프라인 · 키 없음 · 도메인 미등록) "지도를 불러오지 못했어요" + 목록만.
- 데이터가 비면 "아직 보여 줄 곳이 없어요" + 가이드 1장의 온라인 링크로 안내.

## 5. 시험

- 데이터 정리 함수(스크립트에서 분리한 순수 함수): 익산만 거르기 · 읍면동 이름 맞추기 · 사용 안 하는 발급기 빼기 · 좌표 없는 항목 처리 · 0건이면 덮어쓰지 않기.
- 지도 화면(jsdom, SDK 없음): 목록으로 떨어지는지 · 칩 거르기 · 카드 내용 · 길찾기 주소.
- 가이드 1장: 서류마다 온라인 링크, 지도 버튼.
- CSP: 더한 출처가 들어 있고 `connect-src` 는 그대로.
- 정적 빌드를 띄워 CSP 위반이 없는지 실제로 본다(도메인 등록 뒤).

## 6. 순서 (11/23 제출 기준)

1. 온라인 링크(가이드 1장) — 키 없이 바로.
2. 지도 화면 + 주민센터 — 카카오 키 두 개 · 도메인 등록이 오면.
3. 무인민원발급기 — 공공데이터 승인이 오면 데이터만 더한다.

승인이 늦으면 1 · 2 만 먼저 올리고 발급기는 데이터가 생기는 대로 붙인다.

## 하지 않는 것

- 익산 밖 지역 · 전국 검색(앱 대상 지역이 익산뿐).
- 실행 중 카카오 검색 · 주소 변환(쿼터 · CSP · 정확도).
- 신청 준비 화면 서류 목록에서 지도로 바로 가기 — 나중에 같은 화면으로 이을 수 있게만 둔다.
