# 정책 검증 체크리스트

작성일: 2026-09-03
대상 데이터: `apps/web/data/policies.json`의 정책 6건

이 문서는 **현재 데이터가 맞다고 보증하는 문서가 아니라**, 담당자가 공식 공고와
유선 문의로 다시 확인해야 할 내용과 링크를 한곳에 모은 작업 목록이다. 확인을 마치면
각 항목에 체크하고 `policies.json`의 값·`notes`·`verifiedAt`을 함께 갱신한다.

## 먼저 확인할 충돌 4건

- [ ] **익산형 청년월세 모집 방식·인원**: 화면 문구는 `선착순 250명`, 검수 메모는
  `230명, 선착순 아님`으로 서로 다르다. 공고 원문과 익산시 답변을 기준으로 하나로 통일한다.
- [ ] **익산형 청년월세 소득 하한**: 데이터는 중위소득 60% 초과를 요구하지만 공고에는
  130% 이하만 적혀 있다는 메모가 있다. `정부형 청년월세 소득 초과 탈락 이력`이 실제
  신청 요건인지, 단순 설명인지 확인한다.
- [ ] **청년 주거급여 지역별 상한**: 현재 전국 사용자에게 익산이 속한 4급지 1인 가구
  월 21만 2천원을 동일 적용한다. 서울·경기/인천·광역시/세종·그 외 지역별 기준임대료를
  계산에 반영해야 하는지 확인한다.
- [ ] **연세 계약 인정 여부**: 1층은 국토부·익산형 청년월세에 `연세`를 허용하지만 정책
  메모에는 월세만 인정한다고 적혀 있다. 선납 임차료의 인정 방식과 증빙 기준을 확인한다.

## 1. 청년월세 지원 (2026년 상시사업 전환)

- 데이터 ID: `moland-youth-rent-support`
- 현재 내용: 만 19~34세, 청년가구 중위소득 60% 이하·원가구 100% 이하, 실제 월세
  범위에서 월 최대 20만원, 생애 1회 최대 24개월. 데이터상 신청기간은
  2026-03-30~2026-05-29이다.
- 정책 안내: [복지로 2026년 청년월세 지원 신청 안내](https://m.bokjiro.go.kr/ssis-tem/cms/mob/customer/notice/1309500_1155.html)
- 신청 페이지: [복지로 서비스 상세](https://www.bokjiro.go.kr/ssis-tbu/twataa/wlfareInfo/moveTWAT52011M.do?wlfareInfoId=WLF00004661)
- 마지막 데이터 확인일: 2026-08-23

검증할 내용:

- [ ] 2026년 사업이 계속사업이라는 의미와 실제 접수기간을 구분하고, 추가 접수 또는 다음 회차 일정이 있는지 확인
- [ ] 청년가구 재산 1억 2,200만원 이하 등 재산 기준의 정확한 금액과 산정 범위 확인
- [ ] 청년가구·원가구 소득 및 재산에서 원가구 심사를 제외하는 예외 조건 확인
- [ ] 보증금·월세 상한, 전입신고, 본인 명의 계약, 부모와 별도 거주 요건 확인
- [ ] 연세·사글세 등 선납 계약도 지원되는지, 된다면 월 환산 및 이체 증빙 기준 확인
- [ ] 다른 월세·주거비 지원과 중복 수급이 금지되는 범위 확인

## 2. 익산형 청년월세 지원사업

- 데이터 ID: `iksan-youth-rent-support`
- 현재 내용: 만 19~34세 무주택 청년, 보증금 5천만원·월 임차료 60만원 이하,
  청년가구 중위소득 130% 이하·재산 1억 700만원 이하, 월 최대 20만원 × 12개월.
  데이터상 신청기간은 2026-04-15~2026-09-30이다.
- 정책 안내: [복지로 서비스 상세](https://www.bokjiro.go.kr/ssis-tbu/twataa/wlfareInfo/moveTWAT52011M.do?wlfareInfoId=WLF00005488)
- 현재 신청 링크: [익산시청](https://www.iksan.go.kr)
- 마지막 데이터 확인일: 2026-08-30

검증할 내용:

- [ ] **모집 인원이 230명인지 250명인지**, 선착순인지 심사·선정 방식인지 확인
- [ ] 2026-09-30까지 실제 접수 중인지와 정원·예산 소진 여부 확인
- [ ] 익산시청 루트가 아닌 공고 원문 및 실제 신청 안내로 `sourceUrl`·`applyUrl` 교체
- [ ] 정부형 청년월세에 신청해 소득 초과로 부적합 판정을 받은 이력이 필수인지 확인
- [ ] 중위소득 60% 초과라는 하한을 직접 적용하는 것이 맞는지 확인
- [ ] 원가구 중위소득 100% 이하·재산 3억 8천만원 이하 요건과 적용 제외 예외 확인
- [ ] 부모와 별도 거주, 전입신고, 본인 명의 계약, 연세 계약 인정 여부 확인
- [ ] 현재 코드에 없는 원가구 조건을 사용자 질문과 판정에 추가할지 결정

## 3. 전북청년 지역정착 지원사업

- 데이터 ID: `jeonbuk-youth-settlement-support`
- 현재 내용: 만 18~39세, 전북 1년 이상 거주, 지정 업종에 3개월 이상 재직,
  가구 중위소득 150% 이하. 월 30만원씩 최대 12개월이며 포인트 30%와
  익산사랑상품권 70%로 지급한다. 데이터상 2026-04-10 접수 종료다.
- 정책 안내: [익산청년시청 모집공고](https://youthforest.iksan.go.kr/board/view.iksan?boardId=BBS_0000015&menuCd=DOM_000000105002001000&dataSid=46029)
- 신청 사이트: [전북청년 지역정착 지원사업 접수](https://ttd.ezwel.com/)
- 마지막 데이터 확인일: 2026-08-23

검증할 내용:

- [ ] 본모집·추가모집 이후 추가 회차가 없는지 확인
- [ ] 농·임·어업, 중소기업 정규직, 문화예술, 연구소기업 정규직의 세부 인정 기준 확인
- [ ] 재학과 재직을 병행하는 사람이 대상이 되는지 확인
- [ ] 1년 이상 거주 및 3개월 이상 종사 기준일, 전출·퇴사 시 중단 규정 확인
- [ ] 다른 월세지원·주거급여·지자체 현금성 사업과 중복 수급 가능한지 확인
- [ ] 포인트와 지역화폐의 사용처·사용기한·환수 조건 확인

## 4. 익산시 전입 청년 이사비·중개보수 지원사업

- 데이터 ID: `iksan-newcomer-moving-cost-support`
- 현재 내용: 2025-01-01 이후 익산 전입을 마친 만 18~39세 1인 가구, 중위소득
  150% 이하. 이사비 30만원과 중개보수 20만원, 합계 최대 50만원을 생애 1회 지원한다.
- 정책 안내: [익산청년시청 사업 안내](https://youthforest.iksan.go.kr/index.iksan?menuCd=DOM_000000102007000000)
- 신청 사이트: [익산청년시청](https://youthforest.iksan.go.kr)
- 마지막 데이터 확인일: 2026-08-23

검증할 내용:

- [ ] 상시모집이 현재도 열려 있는지와 예산 잔액·조기 마감 여부 확인
- [ ] 전입 기준일, 1인 가구 판단일, 임대차계약·전입신고 선후 관계 확인
- [ ] 소득 확인 기준과 제외 대상(외국인·재외국민 등) 확인
- [ ] 차량대여·운반·포장비와 중개보수 인정 증빙, 청소비 등 제외 항목 확인
- [ ] 온라인 신청의 직접 URL과 제출서류 목록 확인
- [ ] 현재 코드가 판정하지 않는 전입일·1인 가구·소득 조건을 질문에 추가할지 결정

## 5. 청년 주거급여 분리지급

- 데이터 ID: `youth-housing-benefit-split-payment`
- 현재 내용: 부모와 다른 시·군·구에 거주하는 만 19세 이상 30세 미만 미혼 청년,
  원가구 소득인정액 중위소득 48% 이하. 지역별 기준임대료 안에서 실제 임차료를 지급한다.
- 정책 안내: [마이홈 주거급여 안내·선정기준](https://www.myhome.go.kr/hws/portal/cont/selectHousingBenefitView.do)
- 신청 사이트: [복지로](https://www.bokjiro.go.kr)
- 마지막 데이터 확인일: 2026-08-23

검증할 내용:

- [ ] 2026년 중위소득 48% 기준과 가구원 수별 금액 확인
- [ ] 부모 가구가 실제 주거급여 수급가구여야 하는지, 소득 기준만 충족하면 되는지 확인
- [ ] 미혼, 청년 명의 임대차계약, 전입신고 요건과 예외 확인
- [ ] 부모와 다른 시·군·구 요건 및 동일 시·군 예외 승인 기준 확인
- [ ] 사용대차·공동생활가정 등 부모 가구 주거유형에 따른 제외 조건 확인
- [ ] 서울·경기/인천·광역시/세종·그 외 지역과 가구원 수별 기준임대료를 코드에 반영
- [ ] 원가구 소득 질문에서 원가구 가구원 수를 사용하도록 판정 로직 검수

## 6. 전세보증금반환보증 보증료 지원

- 데이터 ID: `jeonse-return-guarantee-fee-subsidy`
- 현재 내용: 신청일 기준 유효한 HUG·HF·SGI 반환보증에 가입한 보증금 3억원 이하
  무주택 임차인. 청년 연소득 5천만원, 청년 외 6천만원, 신혼부부 7천5백만원 이하이며
  납부 보증료를 최대 40만원까지 지원한다.
- 정책 안내·신청: [정부24 전세보증금반환보증 보증료 지원](https://www.gov.kr/portal/rcvfvrSvc/dtlEx/161300000103)
- 마지막 데이터 확인일: 2026-08-31

검증할 내용:

- [ ] 거주지 지자체의 2026년 예산 잔액과 온라인·방문 신청 가능 여부 확인
- [ ] HUG·HF·SGI 상품별 유효 가입 및 보증료 납부 증빙 요건 확인
- [ ] 보증금 3억원 이하와 연소득 기준의 판단 연도·증빙 서류 확인
- [ ] 청년 연령 기준이 지자체 조례마다 다른지와 청년 외 90% 지원 규칙 확인
- [ ] 2025-03-30 이전 가입분 30만원, 이후 가입분 40만원 구분이 정확한지 확인
- [ ] 현재 코드에 없는 보증 가입·보증금·연소득·가입일·납부 보증료 입력을 추가할지 결정

## 검증 완료 처리 기준

정책 하나를 완료로 표시하려면 다음을 모두 충족한다.

- [ ] 공식 공고 원문, 신청 페이지, 담당 기관 답변 중 최소 두 출처를 대조했다.
- [ ] 신청기간·모집 인원·예산 소진 상태를 확인했다.
- [ ] 연령·지역·소득·재산·가구·주택·중복 수급 조건을 확인했다.
- [ ] 지원 금액, 지급 수단, 지급 기간과 실비 한도를 확인했다.
- [ ] `sourceUrl`과 `applyUrl`을 직접 열어 정상 동작을 확인했다.
- [ ] 작성자가 아닌 팀원이 한 번 더 대조했다.
- [ ] `policies.json`, 판정 테스트, `verifiedAt`을 같은 커밋에서 갱신했다.

기존 조사 과정과 과거 수정 내역은
