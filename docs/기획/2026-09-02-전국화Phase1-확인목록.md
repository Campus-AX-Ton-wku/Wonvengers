# 전국화 Phase 1 — 사용자 확인 목록 (누적)

> Phase 1(전북 6개 시 파일럿) 작업 중 Claude 가 원문에서 확인하지 못한 항목을
> 여기 계속 쌓는다. F0-5 원칙대로 확인 안 된 값은 `policies.json`·
> `loan-products.json`에 추정해서 채우지 않았다 — 이 목록이 그 빈 자리다.
> Phase 1 목표가 마무리되면 이 파일을 기준으로 한 번에 정리해 전달한다.

## 사실 확인이 필요한 항목 (지자체 문의·원문 열람)

### 1. 익산시 신혼부부·청년 주택구입 대출이자 지원사업
`data/loan-products.json`(`iksan-youth-home-purchase-loan-interest`)에 등록됨.
첨부 공고문(hwp)을 열 수 없어 다음을 확인하지 못했다.

- 소득기준별 차등 지원 비율 구간표 (몇 % 소득 구간에 몇 %p 씩 지원하는지)
- 재산 기준 유무
- 무주택 요건과의 정합성 — "주택구입"을 전제로 하는 사업인데 무주택자만 대상인지, 이미 구입한 사람도 대상인지
- 지정 대출 상품·취급은행 유무
- 선착순 여부·모집 규모(API는 선착순 1,300명이라 하는데 원문 게시글엔 언급 없음)

### 2. 김제시 청년농촌보금자리 조성사업
`policies.json`·`loan-products.json` 어디에도 넣지 않고 후보 문서에 보류로 기록함
(`docs/기획/온통청년-주거후보.md`의 "검토 완료" 절 참고).

- **김제시가 직접 낸 공고 원문을 찾지 못했다.** "개인 신청형이 아니라 시설 조성 사업이다"는 판단은 농림축산식품부의 전국 사업 개요·타 지자체(하동군) 사례·온통청년 API의 빈 신청 필드라는 정황 증거로 내린 것이지, 김제시 원문으로 확정한 게 아니다
- 지금 조성 진행 상황(설계·착공·완공 예정)
- 완공 후 입주자 모집이 있다면 그 시기와 별도 공고 여부
- 온통청년 API의 `aplyYmd`(2026-12-01~2027-03-31)가 무엇을 뜻하는지 — 완공 예정일 범위인지, 향후 입주자 모집 예정 기간인지

**확인 방법**: 김제시청 인구정책과 또는 건설과에 직접 문의 필요 (전화번호를 원문에서 찾지 못함 — 김제시청 대표전화 063-540-3114를 통해 담당부서 연결 필요)

## 팀 판단이 필요한 항목 (사실 확인이 아니라 제품/스키마 결정)

### 4. 전주시 청춘★별채 — 스키마 갭
이 정책은 매입임대주택을 월 1~2만원 임대료로 공급하는 유형이라 `policies.json`의
`benefitType`(월 상한·정액·일시금, 전부 "지원금 계산" 모델) 어디에도 맞지 않고,
`loan-products.json`(대출·보증료 상품)에도 맞지 않는다. "저가 임대주택 공급형"
정책을 이 앱에 넣을지, 넣는다면 어떤 형태로 표현할지 스키마 확장 여부를 포함해
팀이 판단해야 한다. (사실 확인 문제가 아니므로 위 1~3번과 성격이 다르다.)

### 5. `loan-products.json`의 지역 노출 범위
`/result` 화면의 "이용 가능한 대출·보증 상품" 섹션은 `loan-products.json`의
모든 항목을 **지역 필터링 없이 전체 노출**한다(코드로 확인함, `app/result/page.tsx`).
지금까지는 두 항목(청년전용 버팀목 전세자금대출, 전세보증금반환보증 보증료 지원)이
전부 "전국"이라 문제가 드러나지 않았는데, 이번에 익산·군산 전용 항목을 추가하면서
**다른 지역 사용자에게도 "익산시 대출이자 지원", "군산시 대출이자 지원"이 그대로
보인다.** 코드는 건드리지 않았다 — 지역 필터를 추가할지, 지금처럼 전체 노출을
유지하되 `regionScope` 표시로 충분하다고 볼지는 팀 판단이 필요하다.
