- **승인 (ggue 11/22)**: ① 켜는 방식 = **기기 설정 자동 + '내 정보'에서 선택**(기기 설정 · 밝게 · 어둡게) ② 색은 **Claude 가 지금 토큰에서 다크 짝을 만든다**(대비 계산으로 확인) ③ **제출(11/23) 전에 넣는다**
- **바꾸지 않는 것**: 서버 · 동의 · AWS. 카카오 노란 버튼(카카오 가이드 색), 시작 화면 파랑, 3D 아이콘 · 마스코트 그림(모두 투명 배경이라 그대로)

## 1. 켜는 방식

- 저장: `localStorage["perky.theme"]` = `"system" | "light" | "dark"`, 없으면 `"system"`. **이 기기에만**, 서버로 안 보내고(동기화 목록 밖) 로그아웃해도 남긴다(온보딩 본 기록 같은 기기 설정)
- 정하기: `dark = choice === "dark" || (choice !== "light" && matchMedia("(prefers-color-scheme: dark)").matches)`
- 적용: `<html data-theme="dark|light">` + `style.colorScheme`(네이티브 입력칸 · 스크롤바) + `<meta name="theme-color">`(상단 상태 표시줄 · 브라우저 막대)를 밝게 `#f4f8ff` / 어둡게 `#0c1620`
- **깜빡임 없이**: `<head>` 의 기존 인라인 스크립트(시작 화면 · 첫 화면 기록) 맨 앞에 `THEME_SCRIPT` 를 붙여 그리기 전에 정한다. 스크립트가 실패하면 밝게(CSS 기본)
- **따라가기**: `ThemeWatcher`(SplashGate 옆) 가 기기 설정 바뀜(matchMedia change) · 다른 탭에서 바꿈(storage) · 이 탭에서 바꿈(사용자 지정 이벤트)을 듣고 다시 적용
- `<html suppressHydrationWarning>` — 스크립트가 그리기 전에 단 속성을 React 가 불일치로 보지 않게(시작 화면 class 도 같은 경우)

## 2. 색 — 토큰만 다크 값으로 덮는다

`globals.css` 에 `[data-theme="dark"] { … }` 한 덩어리. Tailwind 의 `@theme` 변수는 layer 안이라 이 덩어리가 이긴다. 화면 코드는 토큰 클래스를 그대로 쓴다.

| canvas | #f4f8ff | #0c1620 | 페이지 |
| surface | #ffffff | #152230 | 카드 · 시트 |
| ink-50 / 100 / 200 / 300 | … | #1a2938 / #1f3042 / #2c405a / #5a7390 | 보조면 / 옅은 면 / 보더 / 아이콘 |
| ink-500 / 600 / 700 / 900 | … | #93a8bf / #b4c4d6 / #cfdae6 / #edf3fa | 보조 · 본문 · 강조 · 제목 글씨 |

| accent-50 / 100 / 400 / 600 / 700 | … | #2a2210 / #3b2f12 / #ffc629 / #f2bd4b / #ffd27a | |

대비(계산): 제목 14.4:1, 본문 9.1:1, 보조 6.6:1, 링크 7.7:1, 금액 11.2:1, 아이콘 3.3:1 — 밝게의 기준(글씨 4.5:1 이상, 아이콘 3:1 이상)을 다크에서도 시험으로 지킨다.

**그림자**: 남색 대신 검정 바탕으로 약하게(카드 · 떠 있는 섬 · 버튼 립). 버튼 테두리 그림자에 박혀 있던 hex 는 토큰 변수로.

**새 토큰** (밝게는 지금 값과 똑같아 보이는 것이 바뀌지 않는다):
- `scrim` — 시트 뒤 어두운 막. 지금 `bg-ink-900/45` 는 다크에서 **흰 막**이 되므로 `bg-scrim/45`(밝게 #0b2a4a, 어둡게 #000000)
- `brand-press` · `danger-press` — 누를 때 진해지는 버튼 바탕. 지금 `bg-brand-700` · `bg-brand-800` · `bg-danger-700` 이 글씨색 토큰과 같아서, 다크에서 글씨용으로 밝히면 흰 글씨 버튼이 안 읽힌다. 바탕 용도만 두 토큰으로(양쪽 다 #1257d1 · #a11f18)
- `floor` — 홈 마스코트 발밑 그림자(밝게 rgba(11,42,74,.2), 어둡게 rgba(0,0,0,.45))

**직접 박힌 색**: 탭 아이콘 안쪽 흰 구멍(`#ffffff` → surface), 셀렉트 화살표 SVG 의 `%233d5875`(다크용 덮개), 로고 SVG(배경 사각형이 박혀 있다 → 다크용 파일 `perky-wordmark-dark.svg`, 배경 없음 · 남색 글자 → #edf3fa).

**`dark:` 변형**: `@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *))` — 로고 바꿔 끼우기 같은 몇 곳만.

## 3. 내 정보 — '화면 모드'

- 자리: '개인정보 처리방침' 링크 바로 위, 로그인 상태와 상관없이(불러오는 중만 빼고)
- 제목 '화면 모드' + 세 칸 고르기(`role="radiogroup"`): **기기 설정 · 밝게 · 어둡게**. 고른 칸은 파랑 채움 + 굵게(색만으로 말하지 않게 `aria-checked`)
- 누르면 바로 바뀐다(저장 + 적용 + 다른 화면에 알림)
