# 홈 화면 + 찜하기 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그인한 사람이 지원금을 찜하고(♡), 정책마다 서류 체크리스트(서류 목록이 있으면 서류별, 없으면 확인 3개)로 준비하고, 홈(`/home`)에서 내 조건 · 지원 요약 · 찜한 정책 진행률을 한눈에 본다.

**Architecture:** Supabase 정책 표에 `documents`(jsonb)를 더해 빌드 때 `PolicyMeta.documents` 로 싣는다. 찜 목록(`saved`)과 서류 체크(`documentChecks`)는 지금의 답 저장 형식(`apps/web/lib/user-data.ts`, 웹 · API 공유)에 **선택 칸**으로 더해 기기 → 계정 동기화를 그대로 탄다. 화면은 공용 로그인 시트 · ♡ 버튼 · 홈 페이지 · 체크리스트 섞기.

**Tech Stack:** Next.js 15 (static export), TypeScript 5.9, Vitest 2 + Testing Library (jsdom), lucide-react, Supabase(Postgres, PGlite 검사), AWS Lambda(API, 같은 검증 파일)

**Spec:** `docs/기획/2026-11-17-홈-찜하기-설계.md`

## Global Constraints

- 찜 · 홈은 **로그인한 사람만**. 로그인을 쓸 수 없는 빌드(환경변수 없음 — 테스트 기본)에서는 ♡ 버튼을 그리지 않고, `/home` 은 `/onboarding` 으로 보낸다
- 로그인 안 했으면 ♡ → 로그인 시트(제목 `로그인하고 찜해 둘까요?`) → `signIn(현재 경로)`. 돌아와서 자동으로 찜하지 않는다
- 찜 목록: 최근 것이 앞, 최대 **50**, 중복 없음, id 형식 `/^[a-z0-9-]{1,100}$/`
- 서류: 이름 1~60자 필수, 메모 0~80자, 정책당 최대 **15**, 이름 중복 불가. 서류 체크는 정책 → 체크한 서류 이름 배열(정책 최대 50)
- `saved` · `documentChecks` 는 저장 형식의 **선택 칸** — 없어도 통과(예전 앱), 읽을 때 없으면 `[]` · `{}`. `SCHEMA_VERSION` · `CONSENT_VERSION` 은 올리지 않는다
- 기기 저장 키 `perky.saved`, `perky.document-checks:<policyId>` — '처음부터 다시' · 로그아웃이 지우는 범위(체크리스트와 같다)
- 홈 진행률: 서류 목록이 있으면 **서류만** 센다 `서류 {done}/{total} 준비`, 없으면 `확인 {done}/3`. 체크리스트 화면 진행률은 서류 있으면 `(자격 + 기간 + 서류) / (2 + 서류 수)`
- 마감 표시: `D-{n}` / `오늘 마감` / `상시`(applicationEnd 없음) / `접수 마감` / `신청 예정`(시작 전) — 서울 날짜 기준
- 홈의 찜한 정책은 마감돼도 지우지 않는다. 정책 데이터에 없는 id 는 그리지 않는다(저장은 둔다)
- 시작 주소 `/`: `localStorage["perky.auth"]` 가 있으면 `/home`, 없으면 `/onboarding`
- 대출 · 저축 안내 상품(`loan-products.json`)은 찜 대상이 아니다
- 화면 문구 해요체, 터치 44px 이상, 아이콘은 `@/app/components/icons` 로만, 공통 컴포넌트는 `@/app/components` 로만
- `apps/web/app/result/BenefitResultCard.tsx` · `lib/benefit-result.ts` · `app/result/ResultState.tsx` 는 건드리지 않는다
- push · PR · Supabase 적용 · 배포는 ⛔ 단계에서 사용자 확인 뒤에만. 그 밖에는 로컬 커밋만

```sql
-- supabase/migrations/20261116233659_documents.sql
-- 정책 서류 목록 (docs/기획/2026-11-17-홈-찜하기-설계.md "4. 데이터")
-- 앱의 신청 준비 체크리스트가 서류 하나하나를 보여 준다. 비워 두면 앱은 지금의 확인 3개를 쓴다.
-- 팀이 공고 원문을 보고 입력한다(추정 금지). 내용 칸이라 고치면 고친 이유 · 버전 +1 · 미검수.

-- 모양: [{ "name": 1~60자, "note"?: 0~80자 }] 1~15개, 이름 중복 없음, 다른 키 없음
create or replace function public.is_valid_documents(d jsonb)
returns boolean
language sql
immutable
set search_path = ''
as $$
  select jsonb_typeof(d) = 'array'
    and jsonb_array_length(d) between 1 and 15
    and not exists (
      select 1 from jsonb_array_elements(d) as e(item)
      where case
        when jsonb_typeof(e.item) <> 'object' then true
        else exists (select 1 from jsonb_object_keys(e.item) as k(key) where k.key not in ('name', 'note'))
          or coalesce(jsonb_typeof(e.item -> 'name'), '') <> 'string'
          or char_length(e.item ->> 'name') not between 1 and 60
          or (e.item ? 'note' and (coalesce(jsonb_typeof(e.item -> 'note'), '') <> 'string'
                                   or char_length(e.item ->> 'note') > 80))
      end
    )
    and (select count(distinct e.item ->> 'name') from jsonb_array_elements(d) as e(item)) = jsonb_array_length(d)
$$;

alter table public.policies
  add column documents jsonb,
  add constraint 서류_형식 check (documents is null or public.is_valid_documents(documents));

comment on column public.policies.documents is '[신청] 신청 서류 목록 [{"name": "임대차계약서 사본", "note": "확정일자 포함"}]. 비우면 앱은 확인 3개(자격 · 기간 · 서류)를 쓴다';
```

```ts
  if (!Array.isArray(v) || v.length > MAX_SAVED) fail(path, "not a list");
  for (const id of v) if (typeof id !== "string" || !POLICY_ID.test(id)) fail(path, "bad policy id");

function parseDocumentChecks(v: unknown, path: string): Record<string, string[]> {
  const entries = Object.entries(record(v, path));
  if (entries.length > MAX_SAVED) fail(path, "too many entries");
  const out: Record<string, string[]> = {};
  for (const [policyId, names] of entries) {
    if (!POLICY_ID.test(policyId)) fail(path, "bad policy id");
```

```ts
const SAVED_KEY = "perky.saved";
const DOCUMENT_CHECKS_PREFIX = "perky.document-checks:";

export function loadSaved(): string[] {
  const v = readJSON<unknown>(SAVED_KEY);
  return Array.isArray(v) ? v.filter((x): x is string => typeof x === "string") : [];
}

export function saveSavedList(ids: readonly string[]): void {
  if (writeJSONSafely(SAVED_KEY, ids)) notifyLocalChange();
}

/** 찜 ↔ 해제. 바뀐 뒤 찜 상태를 돌려준다. */
export function toggleSavedPolicy(id: string): boolean {
  const next = toggleSaved(loadSaved(), id);
  saveSavedList(next);
  return isSaved(next, id);
}

export function loadDocumentChecks(policyId: string): string[] {
  const v = readJSON<unknown>(`${DOCUMENT_CHECKS_PREFIX}${policyId}`);
  return Array.isArray(v) ? v.filter((x): x is string => typeof x === "string") : [];
}

export function saveDocumentChecks(policyId: string, names: readonly string[]): void {
  if (writeJSONSafely(`${DOCUMENT_CHECKS_PREFIX}${policyId}`, names)) notifyLocalChange();
}

function documentCheckIds(): string[] {
  const ids: string[] = [];
  try {
    for (let i = 0; i < window.localStorage.length; i++) {
      const key = window.localStorage.key(i);
      if (key?.startsWith(DOCUMENT_CHECKS_PREFIX)) ids.push(key.slice(DOCUMENT_CHECKS_PREFIX.length));
    }
  } catch {
    // 읽기가 막혀 있으면 없는 것으로 본다
  }
  return ids;
```

```tsx
import { loadSaved, onLocalChange, toggleSavedPolicy } from "@/lib/storage";

/**
 * ♡ 찜 (docs/기획/2026-11-17-홈-찜하기-설계.md "1. 찜하기"). 로그인한 사람만 —
 * 로그인을 쓸 수 없는 빌드에서는 그리지 않는다. 카드(링크) 안에 놓여도 카드 이동을 막는다.
 */
export function SaveButton({ policyId, policyName, className = "" }: { policyId: string; policyName: string; className?: string }) {
  const [available, setAvailable] = useState(false);
  const [saved, setSaved] = useState(false);
  const [loginOpen, setLoginOpen] = useState(false);

  useEffect(() => {
    setAvailable(isLoginAvailable());
    const read = () => setSaved(isSaved(loadSaved(), policyId));
    read();
    return onLocalChange(read);
  }, [policyId]);

  if (!available) return null;

  function onClick(event: MouseEvent<HTMLButtonElement>) {
    event.preventDefault();
    event.stopPropagation();
    if (!hasStoredLogin()) {
      setLoginOpen(true);
      return;
    }
    setSaved(toggleSavedPolicy(policyId));
  }

  return (
    <>
      <button
        type="button"
        aria-pressed={saved}
        aria-label={`${policyName} 찜하기`}
        onClick={onClick}
        className={`focus-ring inline-flex size-11 items-center justify-center rounded-full transition-colors hover:bg-brand-50 ${
          saved ? "text-accent-600" : "text-ink-500"
        } ${className}`}
      >
        <Heart size={ICON_MD} aria-hidden="true" fill={saved ? "currentColor" : "none"} />
      </button>
      {loginOpen && (
        <LoginSheet
          title="로그인하고 찜해 둘까요?"
          description="카카오로 3초 만에 로그인하면 관심 있는 지원금을 모아 두고 신청 준비까지 이어서 볼 수 있어요."
          next={`${window.location.pathname}${window.location.search}`}
          onClose={() => setLoginOpen(false)}
        />
      )}
    </>
  );
}
```

```ts
// apps/web/lib/preparation.ts
import type { ChecklistState } from "./user-data";
import type { PolicyMeta } from "./types";

/** 신청 준비 진행률 · 마감 표시 (docs/기획/2026-11-17-홈-찜하기-설계.md "2 · 3"). */

function documentsDone(policy: PolicyMeta, checked: readonly string[]): number {
  const names = new Set((policy.documents ?? []).map((d) => d.name));
  return checked.filter((n) => names.has(n)).length;
}

const checksDone = (c: ChecklistState) => [c.eligibility, c.period, c.documents].filter(Boolean).length;

/** 홈 카드: 서류 목록이 있으면 서류만, 없으면 확인 3개. */
export function homeProgress(policy: PolicyMeta, checklist: ChecklistState, checked: readonly string[]) {
  const docs = policy.documents ?? [];
  if (docs.length > 0) {
    const done = documentsDone(policy, checked);
    return { kind: "documents" as const, done, total: docs.length, label: `서류 ${done}/${docs.length} 준비` };
  }
  const done = checksDone(checklist);
  return { kind: "checks" as const, done, total: 3, label: `확인 ${done}/3` };
}

/** 체크리스트 화면: 서류 있으면 자격 + 기간 + 서류 하나하나. */
export function pageProgress(policy: PolicyMeta, checklist: ChecklistState, checked: readonly string[]) {
  const docs = policy.documents ?? [];
  if (docs.length === 0) return { done: checksDone(checklist), total: 3 };
  const fixed = [checklist.eligibility, checklist.period].filter(Boolean).length;
  return { done: fixed + documentsDone(policy, checked), total: 2 + docs.length };
}

const DAY = 86_400_000;

export function deadlineLabel(policy: PolicyMeta, todayISO: string): string {
  if (todayISO < policy.applicationStart) return "신청 예정";
  if (policy.applicationEnd === null) return "상시";
  if (todayISO > policy.applicationEnd) return "접수 마감";
  const days = Math.round((Date.parse(policy.applicationEnd) - Date.parse(todayISO)) / DAY);
  return days === 0 ? "오늘 마감" : `D-${days}`;
}
```

```ts
import { resolveAnswers } from "./age";
import { applicationOpenCount, groupPolicies } from "./discovery";

import type { DiscoveryAnswers, PolicyMeta } from "./types";

export function availableCount(policies: PolicyMeta[], answers: DiscoveryAnswers, todayISO: string): number | null {
  if (Object.values(answers).every((v) => v === null)) return null;
  return applicationOpenCount(groupPolicies(policies, resolveAnswers(answers, todayISO)), todayISO);
}

export function savedCards(

): { policy: PolicyMeta; deadline: string; progress: string }[] {
  const byId = new Map(policies.map((p) => [p.id, p]));
  return saved.flatMap((id) => {
    const policy = byId.get(id);
    if (!policy) return [];
    return [{
      policy,
      deadline: deadlineLabel(policy, todayISO),
      progress: homeProgress(policy, read.checklist(id), read.documents(id)).label,
    }];
  });
}
```
