# 앱 시작 화면(스플래시) 설계 (2026-11-20)

- **출처**: 디자인 시안 보드 '로딩 · Perky 블루' · '로딩 설계 노트' + 11/20 시안 검토(`.impeccable/critique/2026-11-20T06-23-24Z__…`)
- **승인**: ggue 11/20 — 시안의 '문구가 떠오르는' 장면 대신 **마크만 정지 화면**, '연결 끊김' 상태는 빼기
- **범위 밖**: 앱 안 뼈대 화면(skeleton) — 따로 정한다

## 왜 시안 그대로가 아닌가

시안은 0ms(마크만, "기기 스플래시와 같은 모습")에서 620ms(문구 포함, "시작 이미지와 같은 마지막 모습")로 문구가 떠오른다.
아이폰은 시작 이미지가 곧 기기 스플래시라 문구가 있던 화면 → 사라짐 → 다시 떠오름으로 되감긴다. 떠오름은 300ms 에 92% 끝나
'0.3초 안이면 움직임 없이' 규칙이 막으려던 깜빡임이 된다. 문구는 소개 1장("흩어진 청년 혜택을 한곳에서 찾아드려요")과 겹친다.
그래서 **기기 화면 · 아이폰 시작 이미지 · 웹 스플래시를 똑같은 한 장**으로 맞춘다.

## 모습

- 바탕 `#1a6bef`(brand-600) 한 색, 정가운데 앱 아이콘(150px — 마크 높이 약 120px). 아이콘 바탕도 같은 색이라 네모가 보이지 않는다
- 문구 없음, 움직임 없음. 걷힐 때만 0.3초 흐려짐(움직임 줄이기면 바로)
- 3초가 넘으면 마크 아래 "조금 오래 걸리고 있어요"(흰 글씨 14px, 4.78:1). **CSS 지연만으로** 띄운다 — 코드가 늦게 받아질 때 필요한 문구라 JS 타이머로는 안 뜬다
- `role="status"` · `aria-label="Perky를 여는 중"`. 덮여 있는 동안 아래 화면은 눌리지 않는다(위에 덮인 판이 받는다)

## 언제 띄우나

**홈 화면 앱(standalone)으로 시작 주소를 열 때, 한 번 열린 동안 한 번.**

- 시작 주소 = `/`(매니페스트 `start_url`)와 `/` 가 보내는 곳 `/home` · `/start` · `/onboarding`
- 띄우지 않음: 브라우저 탭(처음 온 사람은 대부분 링크로 탭에서 들어온다), 카카오 로그인 복귀(`/auth/*`), 알림을 눌러 바로 여는 정책 상세 등 시작 주소가 아닌 곳
- `<head>` 인라인 스크립트가 그리기 전에 `html.splash` 를 단다(START_REDIRECT 와 같은 방식). `/` 에서 다음 주소로 넘어가는 동안에도
  두 문서 모두 첫 그림부터 파랑이라 끊기지 않는다
- 걷는 순간에 `sessionStorage` 에 '본 적 있음'(`perky.launched`)을 적는다 — 넘어가는 중간 문서(`/`)에서는 적지 않는다

## 언제 걷나

문서를 연 지 **최소 1.4초**는 보여 주고 0.3초 흐려지며 걷는다(11/21 1초 → 11/22 ggue "아직 짧다" 1.4초). 이미 1.4초가 지났으면(느린 연결) 바로 흐려지기 시작한다.

> 11/21 바꿈(ggue): 처음엔 '준비되면 바로 · 0.3초 안이면 움직임 없이'였는데, 이 앱은 0.3초 안팎에 떠서 아이폰에서
> 알아보기 어려울 만큼 스쳐 지나갔다. 다른 앱들처럼 1초는 보이게 한다.

## 파랑 하나로

- 앱 아이콘 바탕 `#2f6bff` → `#1a6bef`. 마스터(`docs/디자인/아이콘/perky-icon-2048.png`)에서 스크립트(`scripts/build-app-icons.mjs`)로 색만 바꾸고
  마크 모양 · 위치는 그대로. 파생 4종(`app/icon.png` 512 · `app/apple-icon.png` 180 · `public/icon-192.png` · `public/icon-maskable-512.png` 85%)
- 매니페스트 `background_color` `#f4f8ff` → `#1a6bef` (안드로이드 기기 스플래시)
- 이미 홈 화면에 추가한 아이폰은 아이콘이 바로 바뀌지 않을 수 있다(지웠다 다시 추가하면 바뀐다)

## 아이폰 시작 이미지

- 아이폰은 기종 화면 크기와 **정확히 같은** PNG 를 기종마다 따로 줘야 한다(data URL 은 iOS 17.6+ 에서 안 됨), `apple-mobile-web-app-capable` 메타도 있어야 뜬다
- `scripts/build-apple-splash.mjs` 가 같은 화면을 기종별(세로)로 찍어 `public/splash/` 에 굽는다. 기종 목록은 `lib/apple-splash.json` 하나 —
  스크립트와 `<head>` 의 `<link rel="apple-touch-startup-image" media=…>` 가 같이 읽는다
- 없던 시절에는 아이폰이 흰 화면을 보였다

## 빼는 것

- '연결이 끊겼을 때' 화면 — `public/sw.js` 가 화면 파일을 저장해 두지 않아 오프라인 실행은 브라우저 오류 화면이 뜬다. 기존 `app/error.tsx` 에 맡긴다

## 확인

- 띄울지 판정(인라인 스크립트)을 가짜 `location` · `matchMedia` · `sessionStorage` 로 테스트
- 걷는 컴포넌트 테스트(클래스 제거 · '본 적 있음' 기록 · 0.3초 규칙)
- 빌드 후 Playwright 로 standalone 을 흉내 내 첫 화면 캡처
- 실제 아이폰: 홈 화면에 다시 추가 → 시작 이미지가 파랑인지, 상단 상태 표시줄 칸 색, 앱 아이콘 색
