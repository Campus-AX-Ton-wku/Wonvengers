# Perky 실행 방법

## 준비물

- [Node.js](https://nodejs.org) 설치 (한 번만)

## 실행 순서

1. 저장소 내려받기 (이미 있다면 `git pull`만)

   ```bash
   git clone <레포 주소>
   cd perky-app/apps/web
   ```

2. 의존성 설치 (한 번만, 또는 `package.json`이 바뀌었을 때)

   ```bash
   npm install
   ```

3. 실행

   ```bash
   npm run dev
   ```

4. 브라우저에서 접속

   ```
   http://localhost:3000
   ```

   폰에서 볼 때는 실행 후 터미널에 찍히는 `Network:` 주소를 쓴다.
   맥과 폰이 같은 Wi-Fi에 있어야 한다.

## 끌 때

`npm run dev`를 실행한 터미널 창에서 **Ctrl+C**

## 앱은 `apps/web/` 안에 있다

레포 루트에는 `package.json`이 없다. 반드시 `apps/web/`으로 들어가서 명령을 실행한다.
Vercel·Cloudflare Pages 등에 배포할 때도 **Root Directory 를 `apps/web`** 으로 지정한다.
