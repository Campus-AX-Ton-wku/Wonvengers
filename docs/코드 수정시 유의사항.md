# 코드 수정 시 유의사항

## 사전 준비 (한 번만)

1. GitHub 저장소에 **Collaborator로 초대**되어 있어야 합니다 (저장소 → `Settings → Collaborators`에서 확인)
2. 로컬에 저장소 clone

   ```bash
   git clone https://github.com/nochanyoung/ONE123555.git
   ```

3. 실제 웹사이트 코드는 `docs/웹사이트/safe-bet` 폴더 안에 있습니다. 이 폴더를 Claude Code(또는 사용하는 AI 코딩 툴)로 열어서 작업하면 됩니다.

## 작업 흐름

```bash
git pull                          # 1. 작업 시작 전, 최신 내용 받기
# 2. Claude와 함께 코드 수정 (바이브 코딩)
git add .
git commit -m "수정 내용 설명"
git push                          # 3. 완료된 단위만큼 올리기
```

## 유의사항

- **작업 시작 전 항상 `git pull` 먼저.** 다른 사람이 먼저 고친 내용을 놓치면 충돌이 나기 쉽습니다.
- **한 줄 고칠 때마다 push할 필요는 없습니다.** "이 기능 수정 완료" 같은 의미 있는 단위로 묶어서 commit/push하세요.
- **같은 파일을 여러 명이 동시에 고치면 충돌(conflict)**이 날 수 있습니다. push 전에 `git pull`로 다른 사람의 변경 사항이 있는지 먼저 확인하세요.
- 실행 방법은 [웹사이트-실행방법.md](./웹사이트-실행방법.md) 참고
